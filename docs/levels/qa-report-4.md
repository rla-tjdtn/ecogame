## 1. 모든 장에 걸친 남은 문제(우선 처리)

1. **Studio 재실행(1·2·3·5·7·8·9·10장).** 새 방화 셔터 벽 + 쪽문(1·2·7·10장), 바위 기둥 섬(5장), 3장 새 평면(물길 칸 약 300, 차단벽 아래 물길), 9장 샤프트 옆 2칸 꺾인 차로, 8장 실내 놀이터 한 칸 틈 (r29 c35). 특히 3장은 평면을 통째로 다시 그렸으므로 mapnav·부품을 꼭 다시 잴 것.
2. **괴물 4~5마리 장의 잡힘·기다림.** 7장 128/200·17/200(8.5%), 10장 134/200·13/200(600판 7.7%), 9장 124, 8장 116. 7·10장은 시야를 다 끊었는데도 잡힘이 그대로다 — 도구가 시야를 쓰지 않으니 숫자보다 **숨는 곳 L 위치(갈림목 가까이)·우회 고리**로 다뤄야 한다. 기다림은 두 장 모두 실패선(10%)과 2%p 안 — 문을 하나 더하면 넘는다.
3. **"길 N갈래" 수치.** 7·9·10장 4갈래는 넓은 복도·주차 격자·영사실 겹문의 다른 줄을 두 번 센 것(그림 확인 — 실제 3). 8장은 도구도 그림도 2.
4. **최단이 기준 아래 끝(128~130)에 다섯 장(3·6·7·8·10).** 문 하나 바꾸면 125 밑이 될 수 있다.
5. **바라는 소품(소품 세션):** 셔터 벽면(1·2·7·10장의 "가운데 벽 + 양쪽 쪽문" 이 음파로 셔터로 읽히게), 3장 수문 틀, 2장 도크 레벨러·범퍼. 지금은 일반 벽이라 위치 판단에는 문제없음.
