# STAGE 4 — 폐병원 (2층 건물)

생성기 `tools/places/hospital.js` → `src/server/Stages/Stage4.luau` (`Rows` + 같은 크기 `Rows2`), 전용 장비 `src/server/ChapterProps/Hospital.luau`. 괴물 2마리.
그림: 1층 `../../tools/maps/stage4-map.png`, 2층 `../../tools/maps/stage4-map-2f.png`, 길 지도 `../../tools/maps/stage4-routes.png`(왼쪽 1층, 오른쪽 2층).

## 1. Chapter Theme
진료가 멈춘 종합병원. 남동쪽 당직실에서 깨어나 병동·수술동을 서쪽으로 가로지르고, 본관 중앙 홀을 지나 외래동을 동쪽으로 거슬러 정문 로비로 나간다. 조용한 병실 줄 → 영안실·수술실 → 두 층이 트인 대기 홀 → 무너진 외래 복도 → 로비 순서로 압박이 커진다.

## 2. Core Facility Identity
두 동(북쪽 외래·진료동 / 남쪽 병동·수술동)이 서쪽 중앙 홀에서만 이어지는 ㄷ자 병원. 각 동은 "복도 하나 + 양옆 방 줄"이고 남쪽 동 복도 가운데 간호 스테이션이 트여 있다. 두 동 사이는 동쪽 끝까지 벽이다.

## 4. Optional Supporting Zones
린넨·오물실, 화장실, 원장실, 전공의 당직실, 격리실, 관찰실 A·B·C와 입원 병실(모두 문 하나 — 열쇠 상자 없이 침대와 옷장만).

## 5. Zone-to-Zone Flow
당직실 → (공급실 줄 / 병동 복도 / 직원 계단으로 2층 병동) → 중앙 홀 → (외래 복도 / 대기 홀·약국 / 2층 행정 복도) → 로비. 무너진 천장·침대 더미(외래 x24, 병동 x28, 2층 x11·x30)가 복도를 끊어 방을 가로지르게 한다.

## 7. Landmark Features
시신 냉장고 벽(남서), 수술대·무영등, 트인 간호 스테이션 카운터, 두 층이 트인 대기 홀의 의자 줄, 엑스선 촬영대, 중환자실 가운데 감시 스테이션, 로비 수납 창구.

## 8. Sonar Readability
카운터·침대·냉장고 문처럼 굵은 덩어리 윤곽 위주이고, 커튼·수액 줄·바퀴는 음파를 막지 않는다(blocks=false). 방마다 소품은 벽을 따라 두고 가운데 바닥을 비웠다.

## 9. Gameplay Integration
- 길: 주 121 / 보조 144 / 대체 161 — 세 갈래. 2층을 다 막아도 최단 121 그대로.
- 문 줄이기: 병실·관찰실 둘째 문, 응급실─진료실 샛문, 직원 휴게실·2층 처치실 둘째 문 등 9곳을 없애 길 4갈래·고리 25 → **3갈래·고리 16**. 문이 하나가 된 방의 열쇠 상자(6개)도 뺐다(Z 27 → 21).
- 괴물 하나로 끊기는 곳 0, 둘 무작위 0.0%(S→E), Z→출구 최악 0.5%. 배회 200판 중 기다린 판 12(6%).
- 막다른 병실은 숨기(옷장) 전용, 추격은 중앙 홀과 간호 스테이션 고리에서 따돌린다.

## 10. Visual Authenticity Review (자체 점검)
- 병동·간호 스테이션·외래·응급·영상·약국·수술·영안·중환자실이 다 있고 장비가 용도와 맞는다. ✔
- 약점: 입원 병실이 여럿 비슷하다(실제 병동도 그렇지만 반복감이 있음). 외래 진료실은 둘뿐이다.

## 남은 문제
- 로비 안 두 자리(r3c40 + r5c42)에 괴물 둘이 정확히 서면 출구가 막힌다(경고만, 마지막 방).
- 최단 121칸으로 목표 아래쪽 끝이다.
- Studio 실기(짓기·길찾기·소품 모양)와 사람 플레이는 아직 확인하지 않았다.
