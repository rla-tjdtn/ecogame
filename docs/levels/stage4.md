## 1. Chapter Theme
진료가 멈춘 종합병원. 남동쪽 직원 구역 당직실에서 깨어나, 방화 셔터가 내려진 동쪽 날개를 피해 남쪽 재활치료실 → 서쪽 날개(영안실·부검실 → 응급실)로 크게 돌아 가운데 간호 코어에 닿고, 수술동 복도(또는 영상의학과·외래 복도)를 지나 북동쪽 정문 로비의 멈춘 회전문 옆 비상문으로 나간다.
공포 흐름: 조용한 직원 구역(사물함·샤워실) → 넓은 재활치료실(해방) → 좁은 서쪽 날개 복도와 시신 냉장고 벽(첫 정점) → 침대·커튼이 늘어선 응급실 → 섬처럼 놓인 간호 스테이션(코어, 해방) → 수술대·무영등의 수술동(마지막 정점) → 두 층이 트인 로비(마지막 해방, 출구). 2층 길은 병동(침대·커튼 줄) → 중환자실 → 로비 계단으로 로비에 내려온다.

## 2. Core Facility Identity
실제 종합병원의 "간호 코어 + 병동 날개" 배치. 가운데 간호 코어(x17~33, y16~26: ㅁ자 섬 카운터·엘리베이터 넷. 옛 코어 계단 자리는 무너진 잔해 벽)에서 서쪽 팔(→ 서쪽 날개 복도)과 동쪽 팔(→ 수술동 복도)이 뻗고, 날개마다 "복도 하나 + 양옆 방 줄"(double-loaded)이다.
- 서쪽 날개(x1~15): 세로 복도 x7~9, 서쪽 방 줄(CT·엑스선·응급실·영안실), 동쪽 방 줄(판독실·화장실·소생실·부검실·오물실).
- 동쪽 날개(x35~49): 북쪽 = 정문 로비(y1~11) + 수술동(y13~26, 복도 x41~43), 남쪽 = 직원 구역(y28~41). 그 사이(y27)는 **방화 셔터 B** 로 막혔다.
- 북쪽 가운데 = 외래(진료실 셋·대기실·외래 복도), 남쪽 가운데 = 재활치료실·채혈실·남쪽 복도. 코어 남쪽 팔도 방화 셔터로 막혔다.
- 2층 = 입원 병동 층: 서쪽 병동 A, 남쪽 병동 B, 2층 간호 코어, 동쪽 중환자실(수술동 위), 북쪽 행정·의국. 정문 로비 위는 두 층 트임(`_`).
다른 장의 뼈대와 다르다: S자 가로 띠(2·3·6·10) 아님, 고리 + 봉인 가운데 방(1) 아님 — 가운데 코어는 막힌 마지막 방이 아니라 지나가는 허브다.

## 5. Zone-to-Zone Flow
세 길이 서로 다른 통로로 가서 로비의 서로 다른 입구로 든다(QA 2차):
- 주(1층 코어 길): 당직실 → 탈의실·직원 통로 → 재활치료실 → (검체·이송 뒷문) 병리·부검실 → 서쪽 날개 남쪽 복도 → 서쪽 팔 → (코어 출입문) 간호 코어 → 동쪽 팔 → (수술동 출입문) 수술동 복도 → (수술동 자동문) 로비 남쪽.
- 보조(1층 외래 길): 재활치료실 → 남쪽 복도 → (방화문 x16) → 영안실 → (시신 이송 문) → 응급실 → 서쪽 날개 북쪽 복도(y18 방화 셔터 북쪽) → 외래 복도(x21~22 무너짐 → 대기실로 비켜 감) → 로비 서쪽 입구.
- 대체(2층 병동 길): 남쪽 복도 계단 또는 직원 비상계단 → 2층 병동 B → 병동 A → 서쪽 팔(또는 행정 복도·의국) → 2층 간호 코어 → 중환자실 → 로비 계단 → 로비 동쪽.
서쪽 날개 복도는 응급실 북쪽 문 바로 아래(y18)에서 방화 셔터로 나뉘어, 주 길(남쪽 반)과 보조 길(북쪽 반)이 같은 복도를 쓰지 않는다.

## 7. Landmark Features
가운데 ㅁ자 간호 스테이션 섬, 방화 셔터 두 곳(가로 살 철판), 시신 냉장고 벽, CT 고리, 평행봉, 수술대·무영등, 중환자실 둘레 침대 고리, 로비의 회전문과 유리 바람막이.

## 8. Sonar Readability
굵은 덩어리(카운터·침대·냉장고·셔터 철판) 위주이고, 커튼·수액 줄·바퀴·유리판·평행봉 기둥은 음파를 막지 않는다(blocks=false). 복도에는 들것·휠체어 몇 개만, 방은 벽을 따라 놓고 가운데 바닥을 비웠다. 셔터의 가로 살과 CT 고리는 한 번의 음파에도 모양이 읽힌다.

## 9. Gameplay Integration
- 탐색: 열쇠 상자 22곳(2층 7) — 큰 홀(코어·로비·대기실·재활치료실·ICU), 통과 방(탈의실, 문 둘인 응급실·영안실·6인실), 복도 벽.
- 우회·추격: 고리 12(QA 2차 후). 코어 섬 둘레, 응급실·영안실 문 둘, 재활치료실 문 셋, 2층 의국 ↔ 코어 문, 6인실 문 둘이 추격을 끊는 작은 고리다.
- 숨기: 옷장·사물함 L 42곳(QA 2차: 55 → 42, 한 방에 둘이던 곳·화장실·회의실 등에서 뺐다. 모양은 한 문 판자 옷장 `closet`).
- 막힌 길의 대안: 방화 셔터(코어 남쪽, 동쪽 날개)와 무너진 외래 복도(x21~22)는 눈에 보이는 "막힌 지름길"이고, 2층 병동이 1층 서쪽 날개 전체를 대신하는 대체 길이다.

## 10. Visual Authenticity Review (자체 점검)
- 병원 필수 구역(병동·간호 스테이션·외래·응급·영상·약/투약·수술·회복·중환자·영안·재활·검사·행정·직원 구역)이 다 있고, 동선이 실제 병원처럼 코어 ↔ 날개로 이어진다. ✔
- 2층 병실은 모두 침대마다 협탁, 다인실은 커튼 칸막이·수액 걸이가 있다(빈 병실 없음). ✔
- 정문이 회전문 + 비상 여닫이문 + 바람막이 + 수납 창구로 "정문"으로 읽힌다. ✔
- 약점: 약국 조제실이 따로 없다(외래 수납 창구·2층 투약 선반으로 대신). 진료실 셋이 같은 배치다.
