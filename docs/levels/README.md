## 자동 검사 (`node tools/level-graph.js --runs 300`, `node tools/check-layout.js`)

## 남은 일 (QA 4차 기준, 90점 미만 8개 장)
- 2장: 트럭 마당 가운데 섬 하나, 도크 두 갈래 중 하나를 마당 쪽 도크 문으로.
- 3장: 관 하나를 T자·막다른 지선으로(가지 모양), 펌프장 입구 셋을 다른 변으로 나누기.
- 5장: 갈림목마다 음파로 구별되는 랜드마크, 넓은 갤러리 하나 좁히기.
- 6장: 1층 동쪽 객실 줄을 큰 방 둘로.
- 7장·10장: 괴물 4~5마리 장 — 갈림목·방화문 옆 숨는 곳 더하기, 10장 2층 휴게실 칸막이·1층 서쪽 대피 통로 갈래 분리.
- 8장: 길을 일찍 갈라 세 갈래로, 마당 입구 하나를 동벽 북쪽으로.
- 9장: 수직 연결 하나를 가운데·서쪽으로.
- 사람 플레이 테스트(친구들과)는 아직 — 자동 검사와 Studio 자동 길찾기까지만 확인됐다.
