## 1. Chapter Theme (설계 의도)
대형 건물의 2개 층 지하 주차장. 엘리베이터가 **가장 깊은 지하 2층**에서 멈췄다. 기둥 격자 주차장과 설비 통로를 지나 동쪽의 램프·비상계단으로 **바로 위층인 지하 1층**에 올라가, 정산소 옆 출차 게이트(지상 출차 램프 입구)로 빠져나간다. 공포 흐름: 조용한 엘리베이터 홀 → 좁은 설비 통로(압축) → 기둥이 끝없이 반복되는 넓은 주차장(해방, 음파 한 번에 다 안 보임) → 벽으로 둘러싼 램프 통로(압축) → 위층에서도 같은 기둥 번호가 반복되는 혼란 → 차단기가 내려진 게이트.

## 2. Core Facility Identity
- **진짜 겹친 두 층**: 지하 1층(Rows2)이 지하 2층(Rows) 바로 위에 같은 크기로 쌓인다(층 높이 12, 지하 2층 천장 11). 두 층의 **기둥·동 출입구 코어·비상계단실이 같은 자리**라 구조가 위아래로 이어진다.
- **기둥 격자 + 차로**: 층마다 북쪽 주차장(x10~37, y1~14)에 동서 차로 셋(y1~2, 7~8, 13~14, 두 칸 폭)과 맞댄 주차 줄 둘. 기둥 B 는 맞댄 줄 이음선에 4칸마다(차 세 대마다) — 벽 덩어리(#)는 주차 줄 안에 하나도 없다.
- **차는 실제 비율**: 폭 1칸 × 길이 2칸(머리 Q·W·I + 꼬리 q). 빈 칸은 바닥선만(l·y, 지나갈 수 있다).
- **램프**: 순환 차로(x39~40) 동쪽에 벽으로 둘러싼 램프 통로 둘(램프 A y12~13, 램프 B y3~4). 각 램프는 두 차로(x42·x45)가 두 칸 분리대로 나뉜다. 위층에서는 구멍(o) 둘레 난간 + 벽, 아래층이 내려다보이지 않는다.
