# STAGE 9 — 지하 주차장 (1층 격자 + 구덩이 높이의 지하 2층)

생성기 `tools/places/parking.js`(새로 만듦, 옛 `tools/gen-stage9.js`는 이것을 부르기만 함) → `src/server/Stages/Stage9.luau`(파일 전체를 한 번에 씀), 전용 소품 `src/server/ChapterProps/Parking.luau`(새로 만듦: 옛 인라인 소품 10종을 옮기고 새 장비 15종 추가). 괴물 4마리.
그림: 평면 `../../tools/maps/stage9-map.png`, 길 지도 `../../tools/maps/stage9-routes.png`.

## 1. Chapter Theme
대형 건물의 지하 주차장. 엘리베이터로 내려온 방문객이 지하 1층 주차 구역 → 차량 램프 → 지하 2층 → 반대편 램프 → 설비·하역 구역 → 정산소를 거쳐 차량 출구 게이트로 빠져나간다.

## 2. Core Facility Identity
기둥 격자와 맞댄 주차 줄이 넓은 공간을 끊고, 3칸 폭 차량 램프와 비상계단으로 층이 바뀐다. 방·복도 건물이 아니라 "열린 바닥판 + 줄 + 램프" 구조다. 지하 2층은 구덩이 높이(-6)다.

## 4. Optional Supporting Zones
재활용 집하장(x28~33, y29~32, 문 하나 — 숨는 곳만), 지하 2층 서쪽 끝 좁은 배관 통로(x1).

## 5. Zone-to-Zone Flow
엘리베이터 홀 → 주차 구역 A → (칸막이 아치 셋) → B → 램프 / 비상계단 둘 → 지하 2층 D → (방화 구획 틈 셋) → C → 램프 / 비상계단 둘 → 착지 통로 → 하역장(두 칸 폭) 또는 기계실–전기실 → 팬룸 또는 트럭 차로 → 정산 구역 → 게이트. 발전기실과 소화펌프실은 침수 대비로 한 단 올려 지었고 양쪽 계단으로 지나갈 수 있다.

## 7. Landmark Features
차량 램프 경사판, 번호 기둥, 올려 지은 발전기실과 배기관, 저수조 탱크, 하역장에 댄 탑차 두 대와 하역 플랫폼, 큰 팬 두 대, 차단기가 달린 게이트.

## 8. Sonar Readability
맞댄 주차 줄의 한 줄은 벽 기둥(#)으로 끊어 음파 한 번에 보이는 크기로 나눈다. 새 천장 설비(팬·표지·덕트)는 음파를 막지 않는다. 기둥 번호판을 네 면에서 두 면으로 줄이고 보호대 띠를 하나로 합쳐 기둥 하나의 부품을 절반 이하로 줄였다.

## 9. Gameplay Integration
**재는 방법 주의**: 지하 2층의 차 K·기둥 X 는 바닥 높이 때문에 PitTiles 에 들어 있고, `level-graph`는 PitTiles 문자를 지나갈 수 있는 칸으로 본다(게임에서는 막힌다). 그래서 K·X 를 벽으로 바꿔 한 번 더 쟀다("막힘 기준"). 두 기준 모두 통과한다.

| 항목 | 이전 맵 | 새 맵(도구 그대로) | 새 맵(막힘 기준) |
|---|---|---|---|
| 최단 | 138 | 123 | 123 |
| 길 | 3갈래, 끊는 데 1마리 | 3갈래(123,149,159) | 3갈래(123,149,159) |
| 끊는 데 괴물 | 1 | 2 | 2 |
| 목 | 2 | 0 | 0 |
| Z | 10 | 23 | 23 |
| 배회 200판 | — | 5 (2.5%) | 5 (2.5%, c·v 도 막힘) |
| 배회 1000판(다른 시드) | 15.9% | 4.4% | 4.1% |
| 고리 | 5 | 9 | 9 |

- 줄인 방법: ① 하역장–정산 구역을 네 칸 폭 트럭 차로와 팬룸 두 갈래로(이전 한 칸 폭 길 둘이 한 점에서 만나 목이었다), ② 내려가는·올라오는 비상계단을 하나씩 더함, ③ 기계실·전기실에 하역장 문, ④ 정산소를 두 문으로, ⑤ 발전기실의 구석 막다른 자리를 없앰. 길이 너무 많아지지 않게 재활용 집하장의 서쪽 문은 다시 막았고, 지하 2층 방화 구획의 북쪽 틈(y15~16)을 벽 끝 한 칸(y14)으로 옮겨 넷째 길(157칸)을 없앴다.
- 괴물 둘 무작위 0.0%(S→E). 정확히 r36c36 + r39c38(정산 구역 입구)에 둘이 서면 끊긴다(경고).
- 열쇠 상자·숨는 곳은 바닥이 0 높이인 칸에만 둘 수 있어, 지하 2층에서는 올려 지은 두 방에만 있다(Z 4곳, L 2곳). 전체 Z 23곳, L 15곳.
- 게임 안 길찾기 규칙(상자 c·배관 v·차를 막힘으로 봄)으로 재도 목 0, 최단 123.

## 10. Visual Authenticity Review (자체 점검)
- 주차장에 꼭 있는 것(엘리베이터 홀, 방재실, 주차 구획, 램프, 비상계단, 발전기·펌프·전기·팬 기계실, 하역장, 집하장, 정산소, 게이트)이 다 있고 차가 다니는 순서로 이어진다. ✔
- 구역마다 그 용도의 장비가 있다. ✔
- 약점: 차 모양이 한 가지(세단)다. 크기·방향만 조금 다르다.
- 약점: 램프가 한 칸(8스터드) 길이라 실제 차량 램프보다 훨씬 짧고 가파르다(구덩이 계단 규칙 때문).
- 약점: 지하 2층이 1층과 같은 격자의 다른 구역이라 실제로 겹쳐 있지 않다(지시대로 구덩이 방식 유지).

## 남은 문제
- Studio 실기(짓기·소품 방향·부품 수·계단 앞 아치·실제 길찾기·음파)와 사람 플레이는 아직 하지 않았다.
- 검사 도구가 PitTiles 의 막는 소품을 지나갈 수 있는 칸으로 본다(`tools/level-graph.js` buildGraph 의 OPEN). Walkable 의 `K = false` 를 읽게 고치면 막힘 기준 줄이 그대로 나온다. 공용 도구라 고치지 않았다.
- 괴물 4마리 배회 흉내 200판 중 102판(막힘 기준 96판)은 잡혀 끝난다. 기준 항목은 아니다.
