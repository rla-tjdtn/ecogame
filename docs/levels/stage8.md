# STAGE 8 — 폐유치원 (1층)

생성기 `tools/places/kindergarten.js` → `src/server/Stages/Stage8.luau`(파일 전체를 한 번에 씀), 전용 소품 `src/server/ChapterProps/Kindergarten.luau`(새로 만듦, 23종). 괴물 4마리.
그림: 평면 `../../tools/maps/stage8-map.png`, 길 지도 `../../tools/maps/stage8-routes.png`.

## 1. Chapter Theme
문 닫은 유치원. 등원 동선을 따라 현관 → 반 교실 → 유희실 → 반대편 반 → 급식 → 바깥 놀이로 하루 일과 순서대로 지나가, 바깥 놀이 마당 북서쪽 후문(가로등 둘)으로 나간다. 모든 것이 어른 허리보다 낮아 괴물이 커 보인다.

## 2. Core Facility Identity
"작은 방 덩어리"(반 교실·낮잠방·화장실·놀이방)가 가운데 **바깥** 놀이 마당을 감싼다. 작은 방(5~6칸)과 문 없이 트인 놀이 공간(책놀이터·볼풀·유희실·급식 홀)이 번갈아 나온다. 마당은 허리 높이 나무 울타리로 나뉘고(음파가 너머로 보인다) 마른 나무·가로등이 서 있다. 마당에는 서로 다른 구역의 울타리 문 둘(동쪽 날개 실내 놀이터 / 남쪽 급식 홀)로 들어간다.

## 4. Optional Supporting Zones
교재·교구 창고(x1~5, y1~7, 문 둘), 교사 화장실(x42~45, y1~7).

## 5. Zone-to-Zone Flow
현관 → 서쪽 복도(또는 화장실–낮잠방–해님반 사슬) → 북쪽 복도(또는 교재 창고–원장실–교무실 사슬) → 유희실 → 동쪽 복도(또는 새싹반–볼풀–실내 놀이터, 무지개반–구름반–블록 놀이방) → 급식 홀(또는 식품 창고–조리실) → 식당 → 마당 남쪽 울타리 문, 또는 동쪽 복도 → 실내 놀이터 → 마당 동쪽 울타리 문 → 낮은 울타리 사이 틈으로 놀이기구 마당 → 그네 마당 → 모래 마당 → 북서쪽 후문. 실제 유치원처럼 교무실은 유희실 옆, 조리실은 식당과 식품 창고 사이, 화장실은 현관과 낮잠방 사이에 있다.

## 7. Landmark Features
유희실 무대와 기둥 넷, 볼풀로 내려오는 미끄럼틀, 책놀이터의 놀이집, 마당 한가운데 정글짐과 비뚤어져 멈춘 그네, 마당의 마른 나무 둘, 후문 양옆 가로등, 식당의 낮은 긴 식탁 줄.

## 8. Sonar Readability
소품은 방마다 랜드마크 하나 + 같은 책상 몇 개로 줄여 선이 엉키지 않게 했다. 책상·목마·그네처럼 가는 부품은 음파를 막지 않고(blocks = false), 막는 것은 신발장·가방장·책장 같은 낮은 덩어리뿐이다. 빨간색 없음. 소품 하나는 부품 25개 이하다. 마당 울타리(Q)는 허리 높이 살·가로대만 보이고 음파를 막지 않아(blocks = false) 마당 너머 건물 벽까지 한 번에 그려진다 — 마당이 방이 아니라 트인 바깥으로 읽힌다(몸은 보이지 않는 높은 충돌 판이 막는다).

## 9. Gameplay Integration
- 길: 주 126칸(동쪽 날개 → 실내 놀이터 → 마당 동쪽 문) / 보조 162(급식 홀 → 마당 남쪽 문) / 대체 170. 고리 15.
- 괴물 하나로 끊기는 곳 0. 괴물 둘 무작위 0.1%(S→E), Z→출구 최악 0.3%. 정확히 r18c19 + r15c27(마당 안 첫 울타리의 양 틈)에 둘이 서면 끊긴다(경고).
- 배회(괴물 4마리): 200판 중 기다린 판 16(8%).
- 숨는 곳 L 26곳, 열쇠 상자 Z 27곳(모두 문 둘 이상인 공간이나 마당·홀 벽).

## 10. Visual Authenticity Review (자체 점검)
- 유치원에 꼭 있는 구역(현관·신발장, 반, 낮잠방, 어린이 화장실, 유희실, 교무실·원장실·보건실, 식당·조리실, 마당)이 다 있고 실제 위치 관계로 이어진다. ✔
- 구역마다 그 용도의 가구가 있다. ✔
- 약점: 반 여섯 개의 가구 구성이 비슷하다(반마다 칠판 쪽·풍금·책상 수만 다르다).
- 약점: 마당이 남북 20칸으로 넓어 정글짐 근처(약 10x10)는 한 음파에 다 안 보일 수 있다.
- 약점: 교사 책상·캐비닛·변기·미끄럼틀·볼풀은 공용 소품(Props)을 그대로 쓴다.
- 약점: 빌더에 바깥 칸(하늘)이 없어 마당 위에도 천장(14)이 있다. 낮은 울타리·나무·가로등과 트인 음파 선으로 바깥을 나타낸다.

## 남은 문제
- Studio 실기(짓기·소품 방향·부품 수·실제 길찾기·음파)와 사람 플레이는 아직 하지 않았다. 새 소품의 모양과 방향은 화면으로 확인하지 못했다.
- 마당 입구는 둘(남·동)이다. QA 가 바란 "세 길이 서로 다른 입구"는 셋째 입구(서쪽·북쪽)가 지름길이 되어 최단 125 를 지킬 수 없어 둘로 했다(주 경로는 동쪽, 보조는 남쪽 문).
- 최단 126 은 기준(125~145)의 아래 끝이다.
- 배회 흉내 200판 중 109판은 괴물에게 잡혀 끝난다(괴물 4마리, 숨기 없이 걷기만 하는 흉내). 기준 항목은 아니지만 난이도가 높다는 뜻이다.
