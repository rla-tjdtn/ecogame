# STAGE 8 — 폐유치원 (1층)

생성기 `tools/places/kindergarten.js` → `src/server/Stages/Stage8.luau`(파일 전체를 한 번에 씀), 전용 소품 `src/server/ChapterProps/Kindergarten.luau`(새로 만듦, 23종). 괴물 4마리.
그림: 평면 `../../tools/maps/stage8-map.png`, 길 지도 `../../tools/maps/stage8-routes.png`.

## 1. Chapter Theme
문 닫은 유치원. 등원 동선을 따라 현관 → 반 교실 → 유희실 → 반대편 반 → 급식 → 바깥 놀이로 하루 일과 순서대로 지나가, 놀이 마당 뒷문으로 나간다. 모든 것이 어른 허리보다 낮아 괴물이 커 보인다.

## 2. Core Facility Identity
"작은 방 덩어리"가 ㄷ자로 가운데 놀이 마당을 감싼다. 작은 방(5~6칸)과 문 없이 트인 놀이 공간(책놀이터·볼풀·유희실·급식 홀)이 번갈아 나온다. 마당은 마지막에만 들어간다.

교재·교구 창고(x1~5, y1~7, 문 둘), 교사 화장실(x42~45, y1~7).

## 5. Zone-to-Zone Flow
현관 → 서쪽 복도(또는 화장실–낮잠방–해님반 사슬) → 북쪽 복도(또는 교재 창고–원장실–교무실 사슬) → 유희실 → 동쪽 복도(또는 새싹반–볼풀–실내 놀이터, 무지개반–구름반–블록 놀이방) → 급식 홀(또는 식품 창고–조리실) → 식당 → 울타리 문 두 곳 → 놀이기구 마당 → 그네 마당 → 모래 마당 → 뒷문. 실제 유치원처럼 교무실은 유희실 옆, 조리실은 식당과 식품 창고 사이, 화장실은 현관과 낮잠방 사이에 있다.

## 7. Landmark Features
유희실 무대와 기둥 넷, 볼풀로 내려오는 미끄럼틀, 책놀이터의 놀이집, 마당 한가운데 정글짐과 비뚤어져 멈춘 그네, 식당의 낮은 긴 식탁 줄.

## 8. Sonar Readability
소품은 방마다 랜드마크 하나 + 같은 책상 몇 개로 줄여 선이 엉키지 않게 했다. 책상·목마·그네처럼 가는 부품은 음파를 막지 않고(blocks = false), 막는 것은 신발장·가방장·책장 같은 낮은 덩어리뿐이다. 빨간색 없음. 소품 하나는 부품 25개 이하다.

## 9. Gameplay Integration
- 길: 주 126칸 / 보조 158 / 대체 188. 고리 15(이전 24).
- 괴물 하나로 끊기는 곳 0(이전 2: 교재 창고·교구실의 열쇠 상자). 막다른 방이던 두 곳은 옆문을 내 두 문 방으로 바꾸었고, 복도 A 양 끝 막다른 자리의 열쇠 상자는 뺐다.
- 괴물 둘 무작위 0.1%(S→E), Z→출구 최악 0.3%. 정확히 r18c27 + r18c19(마당 둘째 울타리의 양 틈)에 둘이 서면 끊긴다(경고).
- 배회(괴물 4마리): 200판 중 기다린 판 **14(7%)**. 다른 시드 둘로 1000판씩 돌리면 4.7%·4.8%. 이전 맵은 13/60(22%)였다. 줄인 방법: ① 급식 홀을 네 칸 폭으로(괴물이 서도 옆으로 지난다), ② 책놀이터·볼풀을 복도로 트고 달님반·새싹반·실내 놀이터를 세 칸 폭 접이문으로 이음, ③ 유희실–새싹반 옆문, ④ 교재 창고–원장실 옆문(북쪽 셋째 갈래), ⑤ 마당 울타리 문을 세 칸·두 칸 폭으로.
- 숨는 곳 L 26곳, 열쇠 상자 Z 27곳(모두 문 둘 이상인 공간).
- 게임 안 길찾기 규칙(상자 c를 막힘으로 봄)으로 재도 목 0, 최단 126으로 같다.

## 10. Visual Authenticity Review (자체 점검)
- 유치원에 꼭 있는 구역(현관·신발장, 반, 낮잠방, 어린이 화장실, 유희실, 교무실·원장실·보건실, 식당·조리실, 마당)이 다 있고 실제 위치 관계로 이어진다. ✔
- 구역마다 그 용도의 가구가 있다. ✔
- 약점: 반 여섯 개의 가구 구성이 비슷하다(반마다 칠판 쪽·풍금·책상 수만 다르다).
- 약점: 마당이 남북 20칸으로 넓어 정글짐 근처(약 10x10)는 한 음파에 다 안 보일 수 있다.
- 약점: 교사 책상·캐비닛·변기·미끄럼틀·볼풀은 공용 소품(Props)을 그대로 쓴다.
