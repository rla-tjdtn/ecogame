## 1. 모든 장에 걸친 남은 문제(우선 처리)

1. **"3갈래"가 마지막에 한 통로로 모인다.** 도구의 갈래 수는 맞지만 그림으로 보면 4·7·10장은 두 갈래가 마지막 20~40칸을 같은 넓은 복도로 간다(4장 c41~43, 7장 c42~45 → r1~4, 10장 c1~4). 6장은 세 갈래가 모두 동쪽 복도 c39~40(1층 또는 2층 같은 자리)을 지난다. 실제로 출구로 드는 "서로 다른 접근"은 장마다 2개다. 규칙상 위반은 아니지만 "진짜 대체 길" 점수는 그만큼 깎았다.
2. **긴 직선 복도가 다시 생겼다.** 1차에서 6장 r12~14(42칸)를 감점했는데, 지금 7장 r1~4(44칸, 4칸 폭)·2층 r32~34(45칸), 8장 r9~10(45칸), 10장 1층 r1~4·2층 r2~4(45칸), 1장 r38~39(43칸)가 같은 문제다. 괴물 4~5마리 장일수록 위험(7장 잡힘 124, 10장 163). 방화문·꺾임·기둥 열로 20칸 안에서 끊을 것.
3. **"바깥 고리" 뼈대가 셋.** 1장(고리 + 봉인된 가운데), 3장(둘레 간선 터널 고리 + 가운데 저수조), 10장(1·2층 둘레 고리 복도 + 가운데 상영관)이 그림에서 같은 모양으로 읽힌다. 1장은 정체성이라 괜찮고, 10장 서비스 고리는 줄여야 한다.
4. **최단이 모두 기준 아래쪽(126~128)에 몰렸다**(4~8·10장). 기준 안이지만 여유가 없다. 문 하나만 바뀌어도 125 아래로 떨어진다.
5. **Studio 미확인이 전부다.** 새 소품(1장 x, 2장 줄 랙·컨베이어, 3장 Channel·DropInlet·PipeBridge·Weir·ManholeShaft, 4장 회전문·셔터, 6장 욕실 칸막이, 7장 8종, 8장 울타리, 9장 차·램프, 10장 좌석) 모양·방향·부품 수, 9장 2층(Rows2) 출구(`StageBuilder.luau:864` 처리 코드는 있음), 4장 51칸 폭 맵. 부품 수는 모두 설계자 추정(3장 9,500 은 한도 끝).
