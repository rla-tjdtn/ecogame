## 1. 모든 장에 걸친 남은 문제(우선 처리)

1. **`straight` 검사 우회.** 1장(r37 소화전 홈 x, `Stage1.luau:59`), 7장(정수기 홈 r5 c26, `Stage7.luau:25`; 조리실 문 r24 c40), 10장(서쪽 통로 홈 r18 c5, `Stage10.luau:39`; 2층 라운지 입구 r23 c27~30)은 2차가 요구한 "방화문·꺾임"이 아니라 옆벽 홈으로 도구 숫자만 줄였다. 3장 간선·10장 영사 회랑은 5칸 폭이라 검사 밖이다. 설계 문서의 "22칸/16·17칸/21칸 안에서 끊긴다"는 시야 기준으로 **틀린 보고**다.
   - 도구 제안: 폭을 칸마다 재지 말고 띠의 중앙값 폭으로 재고, 폭 상한을 6으로 올리고, 줄 하나가 아니라 "띠 안 어느 줄이든 열린 시야"로 잴 것(검토자 스크립트와 같은 방식).
2. **"길 N갈래" 수치와 실제.** 7·9·10장 4갈래는 넓은 복도·주차 격자의 다른 줄을 두 번 센 것(설계자 설명이 맞음 — 그림 확인). 3장 3갈래 중 둘은 같은 간선 터널의 양쪽 둑(물길 한 칸 사이)이다. 8장은 도구도 2갈래다.
3. **최단이 기준 아래 끝(128~130)에 다섯 장(5·6·7·8·10).** 기준 안이지만 문 하나에 125 밑으로 떨어진다.
4. **잡힘(흉내 플레이어 사망)이 4~5마리 장에서 높다:** 7장 139/200, 10장 132/200, 8·9장 115. 셋 다 긴 4칸 폭 시야와 겹친다(7·10).
5. **Studio 미확인(전 장):** 부품 실측(6장만 10,578 측정값 있음), 새 소품 모양·방향(5장 광차 섬·바위 기둥, 8장 둘레 울타리, 9장 철망 칸, 10장 플래터·돌린 상영관), 2층 출구(9장 Rows2 E), 3장 간선 다리 b 일곱 건너기, 4장 51칸 폭.

## 판정 기준 메모

- 자동 실패 조건(소프트락, 대체 길 없음, 괴물 길 깨짐, 출구 못 감, 소품이 막은 통로, bigcut)은 **도구로 찾지 못했다**. 10장 "방 이름만 붙은 열린 띠"는 일반 복도 + 테마 소품에 가깝지만 상영관·로비 핵심 구역이 진짜라 자동 실패가 아니라 건축 점수로 깎았다.
- 직선 시야는 2차와 같은 기준(소품·옆벽 홈은 시야를 끊지 않음)으로 매겼다. 도구 `straight` 의 폭 계산을 고치기 전까지는 이 장들의 "직선 21~22" 를 믿지 말 것.
- 4장 승인은 Studio 결과(51칸 폭, 로비 계단, 부품)가 문제없을 때 확정. 6장은 Studio 재측정에서 부품 ≤ 9,000 이고 길찾기가 정상이면 성능·AI 를 다시 매긴다(최대 +3).
