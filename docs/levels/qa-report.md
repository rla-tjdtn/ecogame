## 1. 모든 장에 걸친 문제(우선 처리)

1. **경로 규칙이 셋으로 갈라져 있다.** level-graph 는 `c`·`v` 를 지나갈 수 있다고 보고, 게임 경로 함수 `info.route`(StageBuilder.luau:263, :815)는 막힘으로 본다. 반대로 게임 경로는 `P` 를 늘 지나갈 수 있다고 본다(`passable` 의 `P = true`). 그런데 `P` 는 장마다 **막힌 소품**이다: 배전반(S1), 팔레트(S2), 신도석(S5, 30칸 — 출구로 가는 예배당 한가운데), 준비대(S6), 오르간(S8), 소화 펌프(S9). 괴물이 `Monster.luau:1323` 에서 이 경로의 몇 칸 앞 점을 PathfindingService 목표로 쓰므로, 목표 점이 신도석 안에 떨어지면 계산 실패 → 더 짧은 구간으로 재시도를 되풀이할 수 있다. **고칠 것:** 한 표(예: 스테이지 파일의 Walkable)로 세 도구를 맞추고, `passable` 에서 `P = true` 를 빼거나 P 를 쓰는 장에서 `Walkable = { P = false }` 를 넣는다. 그 뒤 level-graph 를 다시 돌려 S1·S6 의 기다림 9% 가 10% 를 넘지 않는지 본다.
2. **뼈대가 겹친다.** S1(고리를 돌고 봉인된 가운데 방의 출구)과 S5(나선으로 돌고 가운데 승강장 출구)는 같은 "바깥 고리 → 가운데 마지막 방" 구조다. S2·S3·S6·S10 은 모두 "가로 띠 셋을 S자로, 띠마다 복도 + 나란한 방 사슬"이다. 공통 규칙 6절의 "같은 뼈대 복붙 금지"에 걸린다. 장소 자체가 그런 모양인 하수도·영화관은 괜찮다. S5(미로)와 S6(호텔 1층)은 고쳐야 한다.
3. **출구 앞은 늘 문 두 개짜리 깔때기다.** 모든 장의 2마리 컷 자리가 출구 방 바로 앞(S1 기계실 남문 둘이 같은 복도 C2 에 6칸 간격, S5 예배당 문 둘, S7 현관 문 둘, S8 마당 남쪽 틈 둘). 규칙상 "경고"지만, 괴물 4~5마리 장(7~10)에서는 마지막 구간에서 한 마리가 두 문 사이를 오가며 지키는 상황이 쉽게 생긴다. 출구 방 입구를 **서로 다른 복도**에서 오게 바꾸는 것이 좋다.
4. **잡힘 수가 많다(7장 140, 10장 151/200).** 흉내 플레이어가 단순해서 그대로 믿을 숫자는 아니지만, 괴물 4~5마리 장의 위협이 2마리 장의 두 배 가까이 된다. 숨는 곳(L) 위치와 괴물 수·속도를 Studio 에서 확인해야 한다.
