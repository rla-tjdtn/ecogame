## 1. Chapter Theme
버려진 지하 연구·설비 시설. 경비 초소에서 들어와 통제 구역 → 전기·공조 → 발전 → 냉각 → 자재·창고 → 정비 통로로 시설을 시계 방향으로 한 바퀴 돈 뒤, 봉인된 가운데 기계실의 화물 엘리베이터로 나간다.

## 2. Core Facility Identity
"고리형 순환 + 중앙 봉인 구역". 바깥 고리를 다 돌아야 가운데가 열린다. 구간마다 복도와 방 사슬이 나란히 간다.

## 4. Optional Supporting Zones
탈의실(x1~3, y5~7), 통로 옆 대피 칸 다섯(W1 셋: y17~18 소화전 칸, y24~26, y31~32 / C3 둘), 배전함 칸(x13~15, y19~20, 막다른 곳), 작업장 구덩이 바닥.

## 5. Zone-to-Zone Flow
1구간(동쪽으로): 통제실–기록 보관실–전기실–공조실 방 사슬 ↔ 본 복도(기록 보관실 앞이 무너져 방으로 돌아간다). 2구간(남쪽으로): 발전기 홀 → 냉각 배관 구역 ↔ 동쪽 비상 복도. 3구간(서쪽으로): 아래 복도 ↔ 자재 복도. 4구간(북쪽으로): 창고 북문·서쪽 정비 통로 → C2 서쪽 → 기계실 서쪽 남문(20,21), 또는 구덩이 작업장 북문 → C2 동쪽 → 기계실 동쪽 남문(26,21). C2 가운데(x22)는 방화 셔터가 내려와 막혀 두 남문은 서로 다른 통로에서 온다. 시작에서 나가는 길은 셋(검문 홀, 보안 사무실·출입 복도, 서쪽 정비 통로 위쪽)이다.

## 7. Landmark Features
통제실 상황판, 발전기 넷이 선 발전기 홀(가장 큰 공간), 냉각 배관 선반 미로, 구덩이 작업장의 다리, 경고 줄무늬가 깔린 화물 엘리베이터 앞.

## 8. Sonar Readability
콘솔·캐비닛·배전반은 큰 상자 윤곽 + 앞면 선 몇 줄, 발전기와 공조기는 둥근 송풍기 얼굴로 읽힌다. 상황판과 바닥 줄무늬는 길을 막지 않는다.

## 9. Gameplay Integration
- 길: 주 135칸(검문 홀 → 통제실 → 기록 보관실 → 본 복도 → 발전기 홀 → 냉각 구역 → 자재 복도 → 창고 → 구덩이 작업장 → C2 동쪽 → 동쪽 남문) / 보조 177칸(출입 복도 → 본 복도 서쪽 → 기록 보관실 → 전기실 → 공조실 → 동쪽 비상 복도 → 아래 복도 → 창고 서쪽 → C2 서쪽 → 서쪽 남문).
- 괴물 하나로 끊기는 곳 0. 괴물 둘 무작위 0.4%(S→E), Z→출구 최악 1.9%. 정확히 r19c26 + r19c20(기계실 안, 두 남문 바로 안쪽)에 둘이 서면 끊긴다(경고). 두 남문 앞 통로는 이제 서로 다르다(C2 서쪽/동쪽, 통로 거리 약 40칸) — 한 마리가 두 문 사이를 오가며 지킬 수 없다.
- 배회 200판: 기다린 판 15(7.5%). 같은 맵 400판은 24(6%). 게임 안 경로 규칙과 도구 규칙이 하나로 맞춰졌다(c·v 만 지나감).
- Z 18곳, 숨는 곳 17곳. 막다른 배전함 칸·대피 칸·구덩이 바닥에는 열쇠 상자가 없다.
- 왼쪽 위 구역(초소 x1~3 y1~3, 문 (4,2), 검문 홀·기둥 (7,2)(9,2), 아치 (2,4)(6,4), 탈의실 + 문 (2,8), 보안 사무실 + 문 (9,8), 출입 복도 y9 x1~8)과 장비 정비실 x5~15 y12~17(y15 줄 비움)은 자동 테스트 자리라 한 칸도 바꾸지 않았다(이전 판과 칸 비교로 확인).

## 10. Visual Authenticity Review (자체 점검)
- 통제·전기·공조·발전·냉각·창고·정비가 다 있고 설비 흐름으로 이어진다. ✔
- 위 방 사슬 크기가 이제 바뀐다: 큰 통제실 → 기록 보관실 → 낮고 좁은 배전반 칸(+ 케이블 전실) → 공조실. ✔
- 고리 15(목표 16 이하). ✔
- 약점: 서로 다른 길이 여전히 2갈래다(셋째 길을 내려면 봉인된 기계실에 셋째 문을 내야 하는데, 앞쪽 구역에서 들어오면 최단이 70칸 아래로 줄어 "한 바퀴 돌아 마지막에 들어간다"가 깨진다).
- 약점: 정비 통로 W1·C2 는 한 칸 폭이다(좁은길 16%). 대피 칸으로 끊었다.

## QA 재작업 (qa-report.md "STAGE 1" 항목별)
1. **기계실 셋째 입구 / 출구 깔때기**: 발전기 홀·본 복도 쪽 문은 시작에서 약 60칸 만에 기계실로 들어가는 지름길이 되어(최단 135 → 약 70) 이 장의 "봉인된 가운데" 구조를 깬다. 대신 공통 요구(출구 방 입구는 서로 다른 복도에서)를 따랐다: C2 가운데 (22,22)를 방화 셔터(벽)로 막아, 서쪽 남문은 C2 서쪽(서쪽 정비 통로·창고 북문), 동쪽 남문은 C2 동쪽(구덩이 작업장 북문)에서만 온다. 두 문 앞을 한 마리가 오가며 지킬 수 없다(두 문 사이 통로 거리 약 40칸). 남은 2마리 컷은 기계실 안 두 문 바로 안쪽.
2. **냉각 배관 구역 v·c 정리**: 구역 안에 흩어 둔 배관 v 7칸과 셋째 선반 줄(y34)을 뺐다. 선반 줄은 둘(y29 가운데 틈 2칸, y32 틈 3칸), 구석 배관 둘만 남겼다. 경로 규칙도 하나로 맞춰져(c·v 지나감) 엄격판·기본판 차이가 없다.
3. **서쪽 정비 통로 W1 대피 칸**: 위쪽 y17~18(벽 소화전 함 x + 상자), 아래쪽 y31~32(소화전 함 x + 사물함 L)을 더해 기존 y24~26 칸과 함께 긴 1칸 직선을 세 토막으로 끊는다. 소화전 함은 새 소품 `Facility.HoseCabinet`(벽에 붙은 얕은 함, 밟고 지나감).
- 공포 흐름 지적(위 방 사슬 단조): 전기실을 낮은 배전반 칸(y1~4) + 케이블 전실로 바꿔 방 크기 리듬을 만들었다.
- 부품 수 어림: 소품 칸 약 230칸 × 평균 10부품 ≈ 2,300 + 벽·바닥 ≈ **4,000 이하**.
