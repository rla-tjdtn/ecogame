# STAGE 6 — 호텔 (2층 건물)

생성기 `tools/places/hotel.js` → `src/server/Stages/Stage6.luau` (`Rows` + 같은 크기 `Rows2`), 전용 장비 `src/server/ChapterProps/Hotel.luau`. 괴물 3마리.
그림: 1층 `../../tools/maps/stage6-map.png`, 2층 `../../tools/maps/stage6-map-2f.png`, 길 지도 `../../tools/maps/stage6-routes.png`(왼쪽 1층, 오른쪽 2층).

## 1. Chapter Theme
손님이 사라진 호텔을 "뒤쪽"부터 지난다. 직원 휴게실에서 시작해 직원 구역 → 주방·연회장 서비스 구역 → 식당·라운지 → 프런트 로비로, 무대 뒤에서 무대 앞으로 나간다.

## 2. Core Facility Identity
1층은 실제 호텔처럼 직원 동선(백 오브 하우스)과 손님 동선이 복도로 나뉜 가로 띠 셋, 2층은 코어를 둘러싼 객실 복도 고리(레이스트랙)다.

## 4. Optional Supporting Zones
기계실, 짐 보관실, 청소 창고, 북쪽 객실·스위트(문 하나: 열쇠 상자 없이 침대·옷장만 — 숨어 쉬는 막다른 방).

## 5. Zone-to-Zone Flow
직원 구역 → 서비스 복도 → 가운데 띠를 서쪽으로(서비스 복도 / 주방 / 2층 객실층) → 남쪽 띠 → 로비. 가운데 → 남쪽으로 내려가는 길이 셋: 서쪽 직원 통로(x1~2), **배식 통로**((10,30) 문, 연회 준비 복도 ↔ 레스토랑 앞 — 이번에 추가), 서쪽 비상계단. 계단 셋: 동쪽 주 계단, 가운데 서비스 계단, 서쪽 비상계단.

## 7. Landmark Features
주방 화구 줄과 후드, 볼룸의 기둥·원탁, 긴 프런트 데스크, 바 카운터, 2층 엘리베이터 홀의 문 넷, 똑같은 객실 문이 이어지는 복도 고리.

## 8. Sonar Readability
1층 천장 11에 맞춰 소품은 모두 바닥에서 10 아래. 카운터·세탁기(둥근 문)·바·엘리베이터 문틀처럼 한눈에 구분되는 윤곽이다. 서비스 복도와 객실 복도는 소품을 거의 비웠다.

## 9. Gameplay Integration
- 길: 주 122 / 보조 161(2층 객실층) / 대체 151 — 세 갈래. 2층을 다 막아도 122.
- 배회 줄이기: ① 배식 통로 추가(서쪽 끝 두 길에 괴물이 서면 갇히던 원인) ② 서비스 복도 2 → 3칸 폭(괴물이 벽 쪽이면 비켜 감) ③ 주방 문을 복도 가운데로, 층 린넨실 문을 서쪽 복도로 옮김. 이전 28/200(14%) → **11/200(5.5%)**.
- 길 흩어짐 줄이기: 커넥팅 샛문(북쪽 객실 둘, 스위트 하나), 기계실·볼룸·직원 식당 샛문을 없애 고리 22 → **16**. 문이 하나가 된 객실의 서랍장도 빼 Z 25 → 20.
- 다른 시드 600판 흉내로 다시 재면 기다림 9.5% — 10% 기준에 여유가 작다(공식 시드 200판은 5.5%).

## 10. Visual Authenticity Review (자체 점검)
- 호텔의 앞·뒤 동선이 나뉘고 구역마다 실제 장비가 있다. ✔
- 약점: 객실이 똑같이 생겼다(호텔답지만 반복). 1층 남쪽 띠의 방 높이(4칸)가 낮아 레스토랑이 좁게 느껴질 수 있다.
