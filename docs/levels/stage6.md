## 1. Chapter Theme
손님이 사라진 아트리움 호텔. 직원 휴게실(뒤쪽)에서 깨어나 객실 날개 → 주방·연회장(뒤쪽 서비스 고리) → 반대편 객실 날개 → 레스토랑을 지나,
두 층 높이로 트인 아트리움 로비(분수·샹들리에·프런트 데스크)의 정문 회전문으로 나간다. 출구가 건물 한가운데 보이는데 바로 가는 문이 없다는 것이 이 장의 긴장이다.

## 2. Core Facility Identity
뼈대 = **가운데 아트리움 로비 + ㄷ자 객실 날개(서·북·동, 가운데 복도 양쪽 객실) + 뒤쪽 서비스 고리**.
이전 판의 "맵 폭 전체 가로 복도 여섯 줄"(S자 띠)을 버렸다. 1층 가로 복도는 북쪽 직원 복도(y1~2) 하나와 남서쪽 직원 통로(y33~34, 14칸) 하나뿐이다.
- 객실 날개(1층·2층): 2칸 폭 복도 양쪽에 4x4 객실(문 옆 욕실, 침대+협탁, 창가 책상·TV·짐 받침대, 옷장). 이웃 방은 좌우 뒤집어 욕실이 등을 맞댄다.
- 뒤쪽 서비스 고리(백 오브 하우스): 남서 직원 구역 → 서쪽 직원 서비스 통로(x14, 날개와 로비 사이 벽 속 복도) → 주방 → 직원 복도/볼룸 → 볼룸 배식 뒷문·연회 창고 → 동쪽 직원 서비스 통로(x31~32) → 로비 직원 문. 1층 서쪽 날개 바깥 줄은 세탁실·직원 식당(2층 객실층과 층 구별). 날개 안쪽 서비스실(배선실·린넨실) 넷이 손님 복도와 서비스 통로를 중간에서 잇는다.
- 아트리움: 1층 로비(x16~30, y12~34) 위 2층은 `_`(두 층 높이 빈 공간, 지붕 26까지 트임). 2층 북쪽 가장자리 y12 는 난간 너머로 로비를 내려다보는 갤러리 복도.

## 5. Zone-to-Zone Flow
(QA 2차 재작업 뒤. 세 길이 시작 쪽부터 로비까지 서로 다른 통로로 온다 — 동쪽 날개 복도는 이제 한 길만 쓴다.)
- 주 경로(128, 가운데): 휴게실 → 직원 통로 → 서쪽 날개 복도(또는 서쪽 직원 서비스 통로 x14 → 세척실) → 주방 → 그랜드 볼룸 → 배식 뒷문(37,9) → 연회 창고 → 동쪽 직원 서비스 통로(x31~32) → 로비 직원 문(30,26) → 정문.
- 보조(약 147~153, 1층 동쪽): 휴게실 → 서쪽 날개 → 북쪽 직원 복도(방화문) → 하역장 옆 동쪽 날개 복도(x39~40) → 레스토랑 → 로비 문(31,33) → 정문.
- 대체(약 147~153, 2층): 직원 계단 → 2층 서쪽 날개 → 2층 북쪽 복도(또는 아트리움 갤러리) → 2층 동쪽 날개 → 엘리베이터 홀 → 대계단 → 로비.
- 계단 다섯: 남서 직원 계단(12,36~37), 대계단(로비 북동 29~30,14), 북동 비상계단(42~43,5), 날개 가운데 비상계단 둘(11,19~20 · 44,19~20). 2층은 주 경로를 줄이지 않는다(2층 없이 128).
- 로비(마지막 방) 입구 셋은 서로 다른 길 끝: 레스토랑 문(1층 동쪽 날개에서), 동쪽 직원 서비스 통로 문(볼룸에서), 대계단(2층에서). 대계단 꼭대기와 직원 통로 사이는 벽 한 겹(통로를 그 구간만 1칸)이라 괴물 하나(3x3)가 둘을 함께 막지 못한다.

## QA 2차 재작업 (qa-report-2.md STAGE 6 항목별 + 4차 브리프)
