# STAGE 5 — 심층 미로: 버려진 채석장 납골당(카타콤) (1층)

생성기 `tools/places/maze.js` → `src/server/Stages/Stage5.luau`, 전용 소품 `src/server/ChapterProps/Maze.luau`. 괴물 2마리.
그림: 평면 `../../tools/maps/stage5-map.png`, 길 지도 `../../tools/maps/stage5-routes.png`.
이 보고서는 완성된 맵을 읽고 다시 재서 쓴 것이다(맵은 고치지 않았다).

## 1. Chapter Theme
석회암을 캐낸 옛 지하 갱도에 도시의 유골을 옮겨 쌓은 납골당. 나선 계단으로 내려와 입구층 → 납골 회랑 → 아래 채석층 → 석관실 → 지하 예배당을 지나 옛 수직갱 승강기로 나간다.

## 2. Core Facility Identity
안쪽으로 감기는 나선(시계 방향 3/4 바퀴). 심장(예배당·수직갱)은 시작 계단실 바로 아래에 있지만 한 바퀴를 돌아야 닿는다. 방 건물이 아니라 폭이 바뀌는 갱도와 캐낸 빈 공간이다.

## 4. Optional Supporting Zones
갱부 대기실(x28~34, y5~9), 채석공 우물실(x36~42, y4~9), 붕괴 갱 구덩이 바닥.

## 5. Zone-to-Zone Flow
위 띠: 2칸 폭 갱도 ↔ 검표소–작업장–대기실–우물실 사슬. 동쪽 띠: 동쪽 갱도 ↔ 납골 회랑(뼈 벽 두 섬 사이). 아래 띠: 주 운반 갱도 ↔ 붕괴 갱–하치장–펌프실 사슬. 서쪽 띠: 배수 갱 ↔ 유골 정리실·석관실. 심장은 예배당 서쪽 문 둘(유골 정리실·석관실)과 남쪽 무너진 틈으로 들어가고, 예배당–승강장 문은 둘이다.

## 7. Landmark Features
납골 회랑 한가운데의 해골 원통, 뼈 벽 두 섬, 레일이 깔린 3칸 폭 운반 갱도, 붕괴 갱의 나무 다리, 예배당 제단, 수직갱 권양탑.

## 8. Sonar Readability
뼈 벽은 낱개 뼈가 아니라 큰 덩어리 윤곽 + 앞면 선으로 줄였다. 레일·벽 뼈·명판은 밟고 지나가며 음파를 막지 않는다. 갱도 폭이 1~3칸으로 바뀌어 길 위치를 윤곽으로 구별할 수 있다.

## 9. Gameplay Integration
- 길: 주 127칸 / 보조 183칸.
- 괴물 하나로 끊기는 곳 0. 괴물 둘 무작위 0.4%(S→E), Z→출구 최악 0.6%. 정확히 r24c24 + r16c24(예배당–승강장 문 둘)에 둘이 서면 끊긴다(경고).
- 배회 200판: 기다린 판 10(5%).
- 게임 안 길찾기 규칙(상자 c·배관 v 를 막힘으로 봄)으로 재도 목 0, 최단 127로 같다.
- Z 18곳. 고리 14.

## 10. Visual Authenticity Review (자체 점검)
- 실제 카타콤처럼 채석 갱도 → 납골 → 예배당 순서이고, 채석 장비와 유골이 구역별로 나뉘어 있다. ✔
- '미로'이지만 문을 아무 데나 뚫은 격자가 아니라 나선 동선이다. ✔
- 약점: 보조 길이 183칸으로 주 경로보다 56칸 길어, 서로 다른 길이 2갈래로만 잡힌다.
- 약점: 예배당과 승강장이 넓은 사각 방이라 채석 공간 느낌이 덜하다.
