## 1. Chapter Theme
석회암을 캐낸 옛 지하 채석 갱도에 도시의 유골을 옮겨 쌓은 납골당. 지상에서 나선 계단으로 내려와, 기울어진 지층을 따라 비스듬히 뻗은 갱도를
세 단으로 갈지자를 그리며 내려간다: 입구층(채석 갱도) → 납골층(뼈 벽 회랑·예배당·해골 원형실) → 아래 채석층(붕괴 갱·석재 하치장) → 옛 수직갱 바닥의 케이지 승강기(출구).

## 2. Core Facility Identity
- 방 건물이 아니라 **갱도망**이다: 폭이 1~3칸으로 바뀌며 휘고 갈라지는 갱도, 캐낸 자리에 생긴 크고 작은 빈 방(채굴장), 무너진 곳(붕락)을 돌아가는 우회 갱, 막다른 굴.
- 큰 뼈대는 "갈지자 번개": 1단(북동→서), 2단(서→동), 3단(동→남서). 단마다 갈래가 둘이고 그 사이는 통짜 바위라 지름길이 없다. 단과 단은 큰 방(방주식 채석장, 해골 원형실)에서 만난다.
- 출구는 맵 **가장자리(남서 끝)** 의 수직갱 바닥이다. 1장(바깥 고리 + 봉인된 가운데 방)과도, 다른 장의 가로 띠 S자와도 다르다. 가운데 "봉인된 심장"은 없다.

## 5. Zone-to-Zone Flow
- 1단: 시작 → (가) 북쪽 접근 갱도 → 작업실 → 고양이 구멍 → 채석장 북서 / (나) 우물 갱도 → 우물실 → 붕락 우회 갱 → 채석장 북동. 갈래 사이 샛길 둘(우물실 북쪽 오르막 x30, 옛 시추 굴 x17~18).
- 2단: 채석장 → (가) 납골당 문 → 납골 회랑 → 십자로 → 원형실 북쪽 / (나) 납골당 문 → 예배당 → 예배당 동쪽 갱도 → 원형실 서쪽. 샛길 하나(십자로 남쪽 납골 샛길 x25~26).
- 3단: 원형실 → (가) 남서 석관 회랑 → 조각실 → 석관실 → 수직갱 바닥 **북쪽 입구** / (나) 남동 붕괴 갱(턱·다리·구덩이 바닥) → 석재 하치장 → 운반 갱도 → 수직갱 바닥 **동쪽 입구**. 샛길 하나(조각실 → 하치장 석재 내림 굴 x26~27).

## 7. Landmark Features
나선 계단(시작), 고양이 구멍, 채석장의 바위 기둥 숲, 납골당 문틀, 뼈 벽면이 이어진 회랑과 십자로 뼈 섬, 예배당 제단, 원형실의 해골 원통 + 무덤 등불, 요새 부조, 붕괴 갱 나무 다리, 수직갱 권양탑.

## 8. Sonar Readability
- 갱도 폭이 1~3칸으로 바뀌고 방이 둥글게 깎여(모서리 비스듬) 윤곽만으로 갱도·방이 구별된다. 반듯한 긴 띠가 없다(가장 긴 곧은 구간은 운반 갱도 약 6칸).
- 뼈 벽면 u 는 납골층(회랑·예배당 동쪽 갱도·원형실)에만 한 칸 걸러 둔다(37칸). 채석층에는 없다 → 음파 선의 결로 층이 구별된다.
- 레일·명판·뼈 벽면·문틀은 밟고 지나간다(음파·이동을 막지 않음). 막는 소품은 큰 덩어리 몇 개뿐.

## 9. Gameplay Integration
- 길: 3갈래 — 주 128칸(접근 갱도 → 옛 시추 굴 → 채석장 → 납골 회랑 → 납골 샛길 → 원형실 → 석관 회랑 → 북쪽 입구), 보조 164칸(우물 갱도 → 채석장 → 예배당 → 원형실 → 붕괴 갱 → 하치장 → 동쪽 입구), 대체 176칸(접근 갱도 끝까지 → 채석장 서쪽 → 원형실 동쪽 → 붕괴 갱 → 동쪽 입구).
- 추격: 단마다 갈래 둘 + 샛길이 있어 갈래 사이를 돌아 따돌릴 수 있다. 원형실·채석장은 넓어서(5칸 넘게) 괴물 하나로 막히지 않는다.
- 숨기: 막다른 굴 다섯 곳 끝과 방 구석에 벽장 L 11곳. 궤짝 Z 23곳(갈래 벽, 입구 둘 이상인 방에만).
- 막힌 길 대안: 우물실 서쪽 붕락(F) 앞에서 남쪽으로 휜 우회 갱, 무너진 옛 갱도는 돌무더기로 끝난다 — "막혀서 돌아간다"가 장면으로 보인다.
- 마지막 접근: 출구 방 입구는 서로 다른 갈래 두 개(북쪽 석관실 갱도 / 동쪽 운반 갱도). 둘 사이 갱도 거리는 약 25칸이라 한 마리가 두 입구를 오가며 지킬 수 없다.

## 10. Visual Authenticity Review (자체 점검)
- 일반 구조 + 테마 소품? 아니다: 실제 카타콤처럼 채석층(작업실·우물·채석장·하치장)과 납골층(문틀·뼈 회랑·예배당·원형실)이 구역으로 나뉘고, 갱도망 자체가 비정형이다. ✔
- 빈 방? 방마다 기능 장비가 있다(우물, 권양기, 석재, 신도석·제단, 석관, 권양탑·펌프). ✔
- 빠진 핵심 구역? 입구 계단·명문 문·납골 회랑·예배당·원형실·채석장·수직갱 모두 있다. ✔
- 약점: 3단 지그재그는 큰 눈으로 보면 비스듬한 띠 셋이다(길이 120칸 이상을 내려면 되돌아가는 구간이 필요하다). 띠가 곧지 않고 갈래·방·막다른 굴이 섞여 있어 "가로 띠 + 방 사슬" 과는 다르게 읽히지만, 판단은 QA 몫이다.

## QA 재작업 (qa-report.md "STAGE 5" 항목별)
1. **신도석 P 경로(필수)**: 공통 규칙이 바뀌어(c·v 만 지나감, 나머지 소품은 Walkable 에 적지 않으면 막힘) P 는 막힌 칸이다. 스테이지 파일 Walkable 은 `r, u, N, H`(바닥 레일·벽면 뼈·벽 명판·문틀)뿐. 신도석은 이제 예배당 양옆 두 줄(8칸)뿐이고 예배당은 필수 방이 아니다(납골 회랑 갈래가 따로 있다).
2. **미로답게 다시 짜기**: 곧은 띠·사각 나선을 버리고 휘고 갈라지는 갱도로 전부 새로 팠다(생성기 `drift` = 계단처럼 꺾이는 비스듬한 갱도, 폭 1~3칸, `cave` = 모서리를 깎은 채굴장). 막다른 굴 5곳, 비슷하게 생긴 갈림목(샛길 넷). 큰 길은 3갈래로 유지.
3. **봉인된 심장 버리기**: 가운데 마지막 방이 없다. 출구는 남서 가장자리 수직갱 바닥.
4. **출구 방 입구를 다른 갈래에서**: 북쪽(석관 회랑 갈래)·동쪽(운반 갱도 갈래) 두 입구, 서로 다른 갱도에서 온다 → 3갈래(128, 164, 176).
- 공통 1절 3번(출구 깔때기): 위 4번. 괴물 둘로 끊기는 자리(경고)는 이제 출구 방 **안**(r37c7 + r39c7, 승강기 바로 앞 방 한가운데 둘)뿐이고, 복도 두 문이 아니다.
- 음파 잡음(뼈 벽 48칸·레일 40칸 지적): 뼈 더미 섬 U 9칸, 벽면 뼈 u 37칸(납골층만), 레일 26칸.

## 남은 문제
- Studio 실기(지어지는지, 새 소품 H·F·l·M 모양·방향, 괴물 실제 길찾기, 음파 화면)는 확인하지 않았다(이 작업에서 Studio 금지). 새 소품은 luau-analyze 로 문법만 확인했다.
- 최단 128칸은 기준(125~145)의 아래쪽이다.
- 배회 흉내 기다림 14/200(7%)은 기준 안이지만 시드에 따라 14~19 사이로 흔들렸다.
