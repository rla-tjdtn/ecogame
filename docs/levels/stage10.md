## 1. Chapter Theme
문 닫은 멀티플렉스. 관객이 들어오는 길(정문 바람막이 → 매표 → 매점·대기 → 검표구 → 상영관 복도 → 상영관)을 그대로 밟다가, 열려 있는 비상문이나 직원 계단으로 관객이 볼 일 없는 뒤쪽(객석 뒤 대피 통로, 2층 영사실, 사무 구역)으로 넘어가 남서쪽 하역장 트럭 셔터로 나간다.

공포 흐름: 조용한 바람막이(안전) → 한눈에 보이는 넓은 로비(해방, 입간판이 사람처럼 선다) → 검표구 뒤 어두운 상영관 복도와 번호판 → 두 층 높이로 트인 상영관(스크린이 복도 쪽, 객석이 뒤로 높아지고 그 위 영사창이 내려다본다) → 객석 맨 뒤 비상문 → 좁은 대피 통로(방화문 둘) 또는 영사기 줄이 늘어선 긴 영사 회랑 → 하역장. 마지막 하역장은 세 방향(북쪽 대피 통로·북쪽 다락 계단·동쪽 탈의실)에서 들어온다.

## 2. Core Facility Identity
실제 멀티플렉스 동선 뼈대: **가운데 로비가 허브**(매표·매점·대기), 북쪽 검표구 둘 → **상영관 복도**, 복도 북쪽에 **계단식 상영관 셋**(2·3·4관: 스크린이 복도 쪽 남쪽 벽, 관객은 스크린 옆 문으로 들어와 계단을 오르는 스타디움식), 남쪽 양옆에 **1관(서)·5관(동)**. 상영관 뒤쪽 위(2층)에 **영사실**: 북쪽 세 관의 영사실은 한 줄로 이어진 **영사 회랑**(필름을 영사실끼리 옮기는 길, 영사기·플래터가 영사창을 따라 늘어섰다), 1·5관 영사실은 상영관 복도 위 **직원 복도**에 붙는다. 로비 위는 **VIP 라운지 → 사무실·회의실 → 필름 금고·휴게실**, 서쪽 위는 **필름 보관 층(공조실·필름 창고·수리실)**. 하역장은 남서.
다른 챕터와 다르다: 1장 같은 "바깥 고리 + 봉인된 가운데"가 아니고(가운데가 열린 출발 허브), 동쪽 둘레 복도·2층 둘레 통로가 없다. 2·3·6장의 가로 띠 S자도 아니다(허브 → 바큇살(상영관) → 뒤쪽 동선).

## 5. Zone-to-Zone Flow
- 관객: 바람막이 → 로비 → 검표구 둘 → 상영관 복도 → 1관·4관·5관 문 / 로비 동쪽 옆문 → 5관.
- 하역장으로 드는 세 갈래(처음부터 끝까지 서로 다른 곳을 지난다):
  - **① 1층 대피 통로(약 137칸)**: 4관 관객 문(30,18) → 객석 옆 통로를 올라 객석 뒤 비상문(40,5) → 대피 통로(2칸 폭, 방화문 둘) 서쪽 → 서쪽 대피 통로(4칸) → 하역장 북쪽.
  - **② 2층 영사실(약 163칸)**: 상영관 복도 동쪽 끝 → 영사 계단실 계단 → 계단실 북쪽 철문 → 4관 → 3관 → 2관 영사실(사이 벽 철문) → 공조실 → 필름 창고 → 수리실(방마다 철문) → 다락 → 하역장 계단(북쪽 벽).
  - **③ 2층 직원 구역(최단 130칸)**: 로비 옆문 → 5관 → 스크린 옆 비상문 → 동쪽 비상 통로 계단 → 공조실(철문 둘) → 직원 복도 동쪽 → VIP 라운지(동쪽 입구 → 서쪽 끝) → 사무동(서 → 동) → 필름 금고·휴게실(동 → 서) → 탈의실 계단 → 하역장 동쪽.
- 사다리(갈래 사이 갈아타기): 2·3관 객석 뒤 영사실 계단 (12,7~6)·(24,7~6) 이 1층 대피 통로(2·3관 비상문 경유)와 2층 영사 회랑을, 2층 영사 계단실 남쪽 끝(44~45, 16~18)이 회랑과 공조실을 잇는다. 같은 갈래 안에서 괴물을 만나도 다른 갈래로 옮겨 간다(출구까지 길이는 줄지 않는다).
- 계단 여섯: 영사 계단실 (43,17~16), 비상 통로 (42,27~26), 하역장 (7~6,36), 탈의실 (14,36~37), 2관 (12,7~6), 3관 (24,7~6). 로비에서 바로 2층으로 오르는 계단은 없다(지름길 방지).

## 7. Landmark Features
상영관마다 벽을 채운 스크린(찢어져 늘어짐), 두 층 높이 객석과 영사창, 뒤로 갈수록 높아지는 좌석 단, 영사 회랑에 줄지어 선 영사기·플래터 원판(멀리서도 둥근 원판 셋이 읽힌다), 로비 한가운데 매점 섬, 복도의 큰 번호판 1~5, 3관의 무너진 앞줄, 로비 입간판, 하역장 트럭 셔터.

## 8. Sonar Readability
- 좌석: 한 칸 = 긴 의자 덩어리 + 팔걸이 선(부품 4~5). 좌석 칸 129.
- 영사실 셋(각 5칸 폭): 영사기·플래터는 영사창 쪽(y5), 선반·랙은 뒷벽 쪽(y1). 영사실 사이는 벽 + 철문 둘이라 음파 한 번에 한 방만 보인다(45칸 회랑 시야 없음).
- 필름 보관 방 셋·서쪽 대피 통로는 4칸 폭, 소품은 벽에서 띄운 섬 또는 구석에만 둔다. 방 사이 철문은 줄마다 엇갈려(x2·x3·x2) 문틀 너머로 다음 방이 일직선으로 보이지 않는다.
- 플래터는 얇은 원판 셋(음파 고리 1) + 감긴 필름 둘 — 굵고 둥근 윤곽. 빨간색 없음.

## 9. Gameplay Integration
- 길: 위 5절 세 갈래(130·137·163) — 하역장으로 드는 접근이 북쪽 대피 통로·다락 계단·동쪽 탈의실로 셋 다 다르다. 2층을 다 막아도 1층 갈래만으로 132(2층이 지름길이 아니다).
- 괴물 하나(3x3)를 어디 세워도 시작→출구·시작→각 Z·각 Z→출구가 끊기지 않는다(목 0). 괴물 둘로 끊기는 곳은 시작 바람막이 앞(45칸)뿐이다(bigcut 통과).
- 배회(괴물 5): 200판 13판(6.5%), **600판 46판(7.7%)**. 흉내 플레이어 잡힘 134/200(600판 408 = 68%).
- 숨는 곳 L 29(1층 18·2층 11): 상영관 구석·복도 끝·탈의실 사물함·화장실·영사실·사무동.
- 추격: 매점 섬 한 바퀴, 2·3관(비상문 둘 + 영사실 계단) ↔ 대피 통로 ↔ 영사 회랑 사다리, 영사 계단실 ↔ 공조실, 넓은 영사 회랑·라운지에서 괴물 옆으로 빠지기.

## 10. Visual Authenticity Review (자체 점검)
- 로비·매표·매점·대기·검표·상영관(스타디움식 좌석·스크린·통로 발밑등)·영사실(영사기·플래터·되감기·랙·필름 선반)·사무·화장실·탈의실·하역장이 다 있고 로비가 허브다. ✔
- 상영관끼리 벽 구멍 없음. 비상문은 실제 자리(객석 뒤·스크린 옆). ✔
- 2층 영사실이 "영사실 사이 연결"로만 이어지는 회랑이 됐다(둘레 통로 아님). 2층 빈 통로 없음(모든 2층 구역에 기능 소품). ✔
- 약점: 북쪽 영사 회랑(2층)과 1층 대피 통로가 같은 북쪽에 겹친다(서로 다른 층, 서로 다른 기능). 서쪽도 1층 대피 통로 위에 2층 필름 보관 층이 있다 — "북·서 두 층" 은 남았다. 동쪽 고리는 두 층 모두 없앴다.
