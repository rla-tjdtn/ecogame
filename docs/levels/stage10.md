## 1. Chapter Theme
문 닫은 멀티플렉스 극장. 관객이 들어오는 길(로비 → 검표구 → 상영관 복도)을 그대로 밟다가, 4관 스크린 옆 비상문이나 비상 복도로 관객이 볼 일 없는 무대 뒤로 넘어가 하역장 비상 셔터로 나간다.

공포 흐름: 조용한 바람막이와 넓은 로비(한 번에 다 보이지만 입간판이 사람처럼 선다) → 검표구를 지나면 4칸 폭 긴 복도와 어두운 상영관 문들 → 상영관 안 좌석 줄이 시야를 끊는다 → 스크린 뒤 무대 뒤 복도(직원 방 문이 줄지어 있다) → 하역장 모서리의 셔터.

## 2. Core Facility Identity
"남쪽 로비 + 가운데 상영관 줄 + 스크린 뒤 직원 띠"를 세 번 가로지르는 띠 구조. 상영관 안은 계단식 좌석과 양옆 통로, 2층은 영사실 줄과 영사 복도라 다른 챕터와 뼈대가 다르다.

## 4. Optional Supporting Zones
1층: 직원 휴게실(문 둘)·탈의실·전기실·청소 창고·필름 반입실(y1~3). 2층: 회의실·사무실, 직원 휴게실·필름 보관실·금고실·비품 창고(y36~41), 공조 기계실·필름 창고·영사 기사실(y1~3), 동쪽 서비스 통로(x43~45, y9~22). 문 하나짜리 방에는 열쇠 상자가 없다(숨는 곳만).

## 5. Zone-to-Zone Flow
- 관객: 정문 → 매표소 → 매점·대기 → 검표구(서쪽) → 상영관 복도 → 상영관.
- 직원: 검표구 옆 계단 → 라운지 → 회의실·사무실 → 동쪽 직원 계단, 또는 영사 복도 → 영사실. 영사실 계단(2·3관 사이 벽 속)은 상영관 복도에서 영사실로 바로 오른다.
- 상영관 → 무대 뒤는 셋: ① 4관 스크린 옆 비상문 (31,9) ② 동쪽 비상 복도 ③ 2층 서비스 통로 → 기계실 층. 1~3관 비상문은 쇠사슬로 잠겼다.
- 무대 뒤: 1층 무대 뒤 복도 또는 2층 기계실 층 → 하역장. 계단은 모두 다섯.

## 7. Landmark Features
상영관마다 벽을 채운 스크린(군데군데 찢어져 늘어짐), 뒤로 갈수록 높아지는 좌석 줄의 계단 윤곽, 매표 창구 8칸의 틀, 복도의 큰 번호판, 3관의 무너진 앞줄, 로비 입간판, 영사실의 릴 두 개짜리 영사기.

## 8. Sonar Readability
- 좌석은 가로로 긴 방석·등받이 선 두 줄 + 단 윤곽이라 줄무늬로 읽힌다. 팔걸이·글줄·손잡이처럼 작은 부품은 음파를 막지 않는다(`blocks = false`).
- 번호판은 막대 숫자, 비상구는 EXIT 글자라 색 없이 읽힌다. 빨간색은 없다.
- 주 복도는 비워 두고 포스터·번호판만 벽에 걸었다. 상자·숨는 곳은 벽감에 넣었다.

## 9. Gameplay Integration
- 길: 주 131칸(상영관 복도 → 4관 → 비상문 → 무대 뒤) / 보조 161(영사실 계단 → 영사 복도 → 2층 서비스 통로 → 기계실 층 → 하역장 계단) / 대체 177(라운지 → 회의실·사무실 → 동쪽 직원 계단 → 비상 복도 → 무대 뒤). 2층을 다 막아도 최단 131 그대로(2층은 지름길이 아니다). 고리 16.
- 괴물 하나(3x3)를 어디 세워도 시작→출구·시작→각 Z·각 Z→출구가 끊기지 않는다(목 0). 이전 설계의 목 셋(로비 r33c15, 2층 영사실 r21c4·r21c39)은 매점 뒤 통로 개방·검표구 넓히기·영사실 열쇠 상자를 복도 벽감으로 옮겨 없앴다.
- 배회: 이전 설계는 600판에 19.2% → 2.8%. 바꾼 것은 ① 상영관 복도·무대 뒤 복도 4칸 폭, ② 열쇠 상자를 벽감으로, ③ 1관·2관 사이 무너진 벽 틈, ④ 남쪽 2층 계단 셋, ⑤ ②→③ 연결 셋, ⑥ 출구를 하역장 모서리로(출구를 막는 칸 7 → 5).
- 추격: 매점 섬을 돌고, 상영관 좌석 줄 둘레를 돌고, 영사 복도 ↔ 상영관 복도를 계단으로 오르내리며 따돌린다. 숨는 곳 L 은 상영관·영사실·탈의실에 많다.

## 10. Visual Authenticity Review (자체 점검)
- 로비·매표·매점·대기·검표·상영관(계단식 좌석·스크린·양옆 통로)·영사실·화장실·직원 구역이 모두 있고 실제 동선 순서로 이어진다. ✔
- 구역마다 그 용도의 장비가 있다. ✔
- 약점: 상영관 천장이 다른 1층과 같은 높이(11)다. 1층 천장 판은 StageBuilder 가 2층 전체에 깔아서 상영관만 뚫을 수 없다. 좌석 단 높이도 거기에 맞춰 낮다(한 줄 0.55, 맨 뒤 2.75).
- 약점: 좌석 칸은 통째로 막혀 있어 좌석 사이로는 들어가지 못한다(양옆·가운데 통로만).
- 약점: 2층 y9~18 은 상영관 위라 서비스 통로 말고는 비어 있다.
