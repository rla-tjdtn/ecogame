## 1. Chapter Theme
밤의 한국 중학교 본관. 당직실에서 시작해 교실 복도·체육관·급식실을 지나 동쪽 홈베이스로, 다시 본관 복도를 따라 중앙 현관 신발장 앞 출구로 나간다.

## 2. Core Facility Identity
두 동(남쪽 교실 동·북쪽 본관)이 동쪽 홈베이스에서만 만나는 ㄷ자 2층 학교. 교실은 앞문·뒷문이 있고 칠판은 서쪽, 사물함·게시판은 뒤 벽. 서쪽에 2층 높이 체육관.

## 4. Optional Supporting Zones

## 5. Zone-to-Zone Flow
당직실 → (1층 복도·교실 앞뒷문 / 체육관 → 급식실 → 조리실 / 2층 복도) → 동쪽 홈베이스(1층·2층) → (1층 본관 복도·교무실 / 2층 본관 복도 → 중앙 계단) → 현관. 계단 네 곳(남서·남동·북동·중앙 현관).

## 7. Landmark Features
체육관 단상과 농구대, 신발장 줄, 급식 식탁 줄과 배식대, 도서관 서가, 음악실 피아노, 양쪽 벽이 사물함인 홈베이스.

## 8. Sonar Readability
책상은 2칸 간격으로 띄워 격자가 또렷하고, 게시판·사물함은 벽면에 붙어 지나갈 수 있다. 복도와 홈베이스 바닥은 비워 긴 벽선이 깨끗하게 읽힌다. 체육관이 "해방", 막힌 복도 옆 교실이 "압축".

## 9. Gameplay Integration
- 길: 주 120 / 보조 141(2층) / 대체 149(체육관 쪽). 도구는 4갈래(120,141,149,140)로 세는데, 넷째(140)는 2층 복도의 막힌 곳(x30)을 북쪽 미술실로 도느냐 남쪽 2-3으로 도느냐의 차이라 실제 구조는 1층 복도·체육관·2층 세 갈래다. **고리 10**이라 "너무 다중" 경고는 없다.
- 배회 줄이기: 두 동을 잇는 동쪽 연결 복도(2칸)와 남북 긴 복도(2칸)에서 괴물 3x3이 폭을 꽉 막던 것이 주원인이었다. 동쪽을 네 칸 폭 홈베이스로, 남북 복도를 세 칸 폭으로 넓혀 이전 31/100 → **13/200(6.5%)**. 다른 시드 480판씩 잰 것은 최종판이 아니라 샛문을 다 둔 변형 4.0%, 다 뺀 변형 6.0%다(최종판은 그 사이 구성).
- 폭을 넓힌 덕에 교실 샛문은 컴퓨터실─2-5─2-6 두 개만 남겼다(3-1~3-3 샛문과 교구실 샛문 제거).
- 괴물 하나로 끊기는 곳 0, 둘 무작위 0.1%, Z→출구 최악 0.8%.

## 10. Visual Authenticity Review (자체 점검)
- 교실·복도·계단·교무실·특별실·급식실·체육관·현관·화장실·방송실·보건실이 다 있다. ✔
- 약점: 폭 4칸 홈베이스와 3칸 복도는 실제 학교보다 넓은 편(괴물 크기에 맞춘 것). 진로상담실(폭 2)·2-6(폭 5)은 좁다. 1층 가운데와 남쪽 동 사이 중정은 없다.

## 남은 문제
- 최단 120칸으로 목표(120~145)의 딱 아래 끝이다. 길 수는 도구 기준 4갈래(고리 10).
- 중앙 현관 안 두 자리(r5c8 + r5c2)에 괴물 둘이 정확히 서면 출구가 막힌다(경고만, 마지막 방).
- 괴물이 4마리라 흉내에서 잡힘이 140/200으로 많다(난이도 쪽, 맵 검사 기준은 아님).
- 이전의 2층 (26,13)(33,13) 샛문은 넣지 않았다(길 흩어짐).
- Studio 실기와 사람 플레이는 아직 확인하지 않았다.
