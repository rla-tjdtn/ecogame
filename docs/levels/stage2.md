## 1. Chapter Theme
밤에 버려진 물류 센터. 물건이 **입고 → 검수 → 냉장·랙 보관 → 출고 대기 → 하역 → 트럭**으로 흐르던 건물을, 플레이어가 그 흐름 그대로 따라 나간다. 화재 경보로 랙 홀의 방화 셔터가 내려와 있어, 홀은 서쪽(냉장 쪽) 입구와 남동쪽 도크 셔터로만 드나든다.

## 2. Core Facility Identity
**한가운데 큰 랙 홀 하나(격자 통로) + 둘레의 기능 구역**. 띠 셋을 S자로 잇던 예전 뼈대를 버렸다. 홀은 가로 통로(2칸) 사이에 등을 맞댄 팔레트 랙 두 줄이 서고, 세로 통로 넷(서쪽 x9~10, 지게차 주 통로 x19~23, 동쪽 블록 사이 x29~30, 동쪽 x36~37)이 직각으로 가로지른다. 홀 남동쪽은 랙을 비운 출고 대기장(넓은 해방 공간). 둘레: 북쪽 = 입고·포장, 서쪽 = 냉장·냉동, 동쪽 = 충전·정비·출하 사무실, 남쪽 = 하역 도크와 트럭 마당.
2층은 1층과 같은 크기 격자로 **약 920칸(지붕 덮인 바닥의 대부분)**를 덮는 진짜 위층이다. 1층 랙 칸을 되풀이하지 않는다: 북쪽 띠 위 관리동(사무실 줄 + 복도), 냉동 창고 위 냉동기 기계실·응축기실, 랙 홀 서쪽 블록 위 **피킹 메자닌**(박스 흐름 선반 + 출고 컨베이어 + 포장 작업대), 랙 홀 동쪽 위 **상부 보관층**(바닥 적치 팔레트 구역 + 낮은 경량 랙 두 줄쌍 + 화물 승강기 승강장), 동쪽 띠 위 **직원 별관**(휴게실·숙직실·출하 기록 보관실). 2층 바닥이 없는 곳은 출고 대기장 위 2층 높이 출고 공간(y29~32), 하역 도크, 트럭 마당뿐이다(다층 물류 센터의 2층 보관층 + 2층 높이 출고장 구성).

## 4. Optional Supporting Zones
포장장 북쪽 포장 칸(동쪽 끝으로만 열린 작업 칸: 숨는 곳), 전산실·탈의실(문 하나: 숨는 곳만, 열쇠 상자 없음), 정문 경비 초소, 탑차가 막은 동쪽 도크 문 셋(문 안쪽 한 칸).

## 5. Zone-to-Zone Flow
시작에서 **서로 떨어진 세 갈래**로 랙 홀에 든다(괴물 하나가 경비실 출구 둘을 함께 막지 못하게 세 출구를 방 세 귀퉁이에 두었다):
① 포장장 → 입고 검수장 → 냉동 전실 → 냉장실 → 홀 서쪽 문 (8,17) ② 1층 직원 통로(방화문) → 홀 북서쪽 문 (9,10) ③ 2층 계단 → 관리동 복도 → 피킹 메자닌 → 남서쪽 계단실 → 홀 남서쪽.
홀은 세로 통로 넷(x9~10·x19~23·x29~30·x36~37)이 있어 괴물 둘로는 가를 수 없다. 홀에서 정문까지도 서로 떨어진 갈래: 도크 셔터 둘 → 하역 도크(4칸 폭이라 괴물 둘이 나란히 서야 막힌다) → 정문 북쪽 문 / 2층(메자닌 → 상부 보관층 → 직원 별관 → 출하 기록 보관실 계단) → 트럭 게이트 통로 → 트럭 마당 → 정문 동쪽. 도크 문 셋(x9·15·21)이 도크와 마당을 잇는다.
홀 북쪽 벽 셔터 셋 x(17·24·32, y10)·포장장 남쪽 셔터 둘·홀 남쪽 벽 셔터 x(20,33)은 닫혀 있다(직원 통로에서 홀이 보이지만 들어갈 수 없다 — 홀은 북서쪽 끝 문으로만).

## 7. Landmark Features
랙 홀의 직각 격자(어디서든 긴 통로 끝이 보인다), 홀 가운데 3칸 폭 지게차 주 통로, 남동쪽 출고 대기장의 랩 기계, 포장장의 15칸 분류 컨베이어, 내려온 화재 셔터 다섯, 도크에 등을 댄 탑차 셋, 2층 메자닌의 컨베이어 등뼈와 계단 구멍 난간.

## 8. Sonar Readability
- 랙을 **줄 하나 = 소품 하나**로 다시 만들었다(`WP.RackRunX/Z`): 머리 칸이 줄 전체를 짓고, 기둥은 두 칸마다 앞·뒤 한 줄, 보는 층마다 줄 길이 하나. 음파 한 번에 짧은 칸막이 선 대신 **긴 수평선 세 줄 + 성긴 세로선**으로 읽힌다. 예전 랙(칸마다 약 20부품, 242칸 ≈ 5,600부품) → 지금 랙 H·h 209칸이 줄 17개, 약 400부품.
- 2층 메자닌 선반은 낮고(7스터드) 판이 기울어 1층 랙과 실루엣이 다르다.
- 화재 셔터는 벽 틈을 채운 큰 판 + 가로 줄무늬 셋: 멀리서도 "막힌 문"으로 읽힌다. 도크 문은 위 벽 + 말린 셔터 통만 있어 "열린 문"으로 읽힌다.
- 벽 배관 확률을 0.3 → 0.2로 낮췄다(배관 하나에 볼트까지 부품 9개 — 선 잡음과 부품 수가 가장 많은 장식).

## 9. Gameplay Integration
- 길(검사 도구, `--runs 600`): 3갈래 — 주 134칸(1층 직원 통로 → 홀 북서쪽 → 격자 대각선 → 도크 셔터 → 도크 → 정문) / 보조 162칸(2층 관리동 → 메자닌 → 상부 보관층 → 별관 → 계단 → 트럭 게이트 → 마당 → 정문) / 대체 151칸(포장장 → 검수장 → 냉동 전실 → 냉장실 → 홀 → 도크). 2층을 다 막아도 최단 134(2층은 지름길이 아니다).
- 괴물 하나(3x3)를 어디 세워도 시작→출구·시작→각 Z·각 Z→출구가 끊기지 않는다(목 0). **시작 → 출구를 끊는 데 괴물 3마리 이상**: 괴물 둘을 어디에 세워도 맵이 둘로 갈리지 않는다(경비실 안 14칸만 예외).
- 출구 깔때기: 정문은 도크(북쪽 문)와 트럭 마당(동쪽) 두 통로에서 들어오고, 그 두 통로는 홀 셔터·2층 별관 계단으로 서로 다른 곳에서 온다.
- 숨기: 숨는 곳 L 27곳(탈의실 사물함 넷, 각 구역 모서리, 통로 벽). 열쇠 상자 Z 28곳(2층 11곳)은 모두 문 둘 이상인 공간·통로 벽·넓은 홀에 있다.
- 공포 흐름: 조용한 경비실 → 좁은 직원 통로(방화문, 닫힌 셔터 너머 홀) 또는 차가운 냉동 창고(랙 숲) → 넓고 어두운 랙 홀(격자, 어느 통로에서 괴물이 나올지 모름) → 출고 대기장(해방, 하이베이 위로 2층 난간) → 길고 넓은 도크의 마지막 질주와 탑차 사이 마당.

## 10. Visual Authenticity Review (자체 점검)
- 실제 물류 센터 구역(입고·검수, 포장·분류, 랙 보관, 냉장·냉동, 출고 대기, 하역 도크, 트럭 마당, 충전실, 정비실, 출하 사무실, 경비실, 관리동, 전산실, 피킹 메자닌)이 다 있고 물건 흐름 순서로 이어진다. ✔
- "일반 복도 + 창고 소품"이 아니다: 큰 랙 홀 하나가 맵의 가운데 1/3을 차지하는 개방 평면이다. ✔
- 구역마다 용도 장비가 있고 빈 방이 없다(전산실 서버 랙, 탈의실 사물함, 정비실 작업대, 기계실 냉동기). ✔
- 약점: 홀 랙 줄 길이가 두 가지(8칸·5칸)뿐이라 반복감이 조금 있다 — 출고 대기장·주 통로·셔터가 방향 단서를 준다.
- 2층은 지붕 덮인 1층 바닥(트럭 마당·정문 제외 1,516칸)의 72%. 2층 높이로 남긴 곳은 출고 대기장 위·하역 도크뿐이다. ✔
- 약점: 상부 보관층은 넓은 바닥 적치 홀이라 1층 랙 홀보다 비어 보인다(부품을 아끼려고 팔레트 적치 위주).

## 남은 문제
- Studio 실기(짓기·부품 수 실측·실제 길찾기·음파 화면)는 아직 안 했다. 이번 판에서 소품 함수는 바꾸지 않았다(Warehouse.luau 그대로).
- "길 3갈래"는 검사 도구 기준 경계값이다: 넷째 후보(냉장실 쪽 갈래가 도크 대신 마당으로 가는 길)가 앞 길과 39% 겹쳐 따로 세지 않는다(기준 35%). 검수장 검수 줄·냉동 전실 팔레트 줄을 늘려 그 겹침을 만들었다 — 이 방들의 소품을 줄이면 4갈래로 셀 수 있다.
- 배회 흉내의 잡힘이 51% 로 여전히 많다(흉내 플레이어는 숨지 않는다). Studio 에서 괴물 속도·숨는 곳 위치를 확인해야 한다.
