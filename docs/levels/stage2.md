# STAGE 2 — 물류 창고 (2층 건물)

생성기 `tools/places/warehouse.js` → `src/server/Stages/Stage2.luau` (1층 `Rows` + 같은 크기 2층 `Rows2`), 전용 장비 `src/server/ChapterProps/Warehouse.luau`. 괴물 2마리.
그림: 1층 `../../tools/maps/stage2-map.png`, 2층 `../../tools/maps/stage2-map-2f.png`, 길 지도 `../../tools/maps/stage2-routes.png`(왼쪽 1층, 오른쪽 2층).

## 1. Chapter Theme
밤에 버려진 2층짜리 물류 센터. 입고 → 검수·포장 → 랙 보관 → 냉장·냉동 보관 → 출고 준비 → 하역 → 컨테이너 야적장으로 물건이 흐르던 건물이다. 플레이어는 북동쪽 경비실에서 출발해 물류 흐름을 거꾸로 거슬러 남서쪽 야적장 철문으로 나간다.

## 2. Core Facility Identity
"높은 랙이 줄지어 선 큰 홀 + 2칸 폭 지게차 통로 + 하역장". 방이 아니라 넓은 홀을 선반이 가르는 공간이라 다른 챕터(방·복도 건물)와 구조가 다르다. 2층은 사무실 메자닌과 랙 메자닌, 남쪽 2층 보관층·2층 사무동.

## 4. Optional Supporting Zones
검수실(막다른 방, 숨는 곳만), 서류 창고(2층, 막다른 방), 출고 사무실(막다른 방), 탈의실(사물함 = 숨는 곳 셋).

## 5. Zone-to-Zone Flow
입고(포장실·검수실, 메자닌 아래) ↔ 냉장실 ↔ 냉동실 ↔ 경비실 / 출고 준비장 → 주 통로 → 랙 보관동 → (주 통로 서쪽 끝) → 아래 보관동 → 사무동 → 충전실·부품 창고 → 하역장 → 야적장. 실제 창고처럼 보관동은 주 통로로 열리고, 하역장은 도크 두 곳(2칸 폭)으로 야적장과 이어진다. 2층은 계단 다섯 개: 보관동 북벽 셋 → 메자닌, 주 통로 서쪽 끝 계단실 → 2층 보관층, 사무동 복도 → 2층 사무실.

## 7. Landmark Features
냉동 창고의 세로 랙 숲, 주 통로를 막은 쓰러진 선반, 충전실 벽의 충전기 줄과 지게차, 하역장 컨테이너, 메자닌 계단 구멍의 난간, 2층 전산실 서버 랙 줄.

## 8. Sonar Readability
랙은 기둥 세로선 + 긴 보 선만 그리게 되어 있어(선 줄임) 줄무늬로 또렷하다. 지게차는 마스트·지붕 기둥이 세로선으로, 컨베이어는 긴 옆판 두 줄로 읽힌다. 증발기·포크·롤러처럼 작은 부품은 음파를 막지 않게 했다(blocks = false). 2층 계단 구멍은 난간 윤곽으로 떨어질 곳이 보인다.

## 9. Gameplay Integration
- 길: 주 139칸 / 보조 192 / 대체 194(서로 다른 길, 주 경로의 1.5배 안). 2층을 다 막아도 최단 139칸 그대로(2층은 지름길이 아니라 가운데 띠의 셋째 길).
- 괴물 하나(3x3)를 어디 세워도 시작→출구·시작→각 Z·각 Z→출구가 끊기지 않는다(목 0). 괴물 둘 무작위 0.2%(S→E), Z→출구 최악 0.3%. 정확히 야적장 두 도크(r32c7 + r38c7)에 둘이 서면 출구 방이 막힌다(경고 — 마지막 방 바로 앞).
- 괴물 2마리 배회 흉내 200판: 피할 길이 하나도 없어 기다린 판 16/200(8%).
- 게임 안 길찾기 규칙(상자 c·배관 v 막힘)으로 재도 목 0이다(아래 둘째 줄). 맵은 고치지 않았다.
- 숨는 곳: 공구 캐비닛 L(보관동 모서리·탈의실·사무실), 랙 사이 시야가 끊겨 추격을 따돌리기 좋다. 열쇠 상자 Z 27곳(2층 10곳)은 모두 문이 둘 이상인 공간이나 통로 벽에 있다.

## 10. Visual Authenticity Review (자체 점검)
- 핵심 구역(랙 보관동·지게차 통로·냉동 창고·하역장·야적장·충전실·사무동)이 다 있고 물류 흐름 순서로 이어진다. ✔
- 구역마다 그 용도의 장비가 있다(지게차·충전기·컨베이어·팔레트·증발기·서버 랙). ✔
- 약점: 2층 남쪽 보관층 홀 셋이 비슷하게 생겼다(랙 줄만 다름). 아래 보관동 다섯 개도 같은 랙 줄이라 반복감이 있다 — 실제 창고가 그렇긴 하지만 랜드마크가 더 있으면 좋다.
- 약점: 경고 표지·바닥 차선 같은 보조 요소는 아직 없다(선 잡음 때문에 일부러 적게).

## 남은 문제

- 사람이 직접 플레이한 검증은 아직 없다.
