# STAGE 3 — 하수도 (1층)

생성기 `tools/places/sewer.js` → `src/server/Stages/Stage3.luau`, 전용 장비 `src/server/ChapterProps/Sewer.luau`. 괴물 2마리.
그림: 평면 `../../tools/maps/stage3-map.png`, 길 지도 `../../tools/maps/stage3-routes.png`.

## 1. Chapter Theme
도시 밑 벽돌 아치 하수 터널과 배수 펌프장. 지상 맨홀 사다리로 내려온 정비 출입구에서 시작해, 물이 흐르는 방향(위 터널 → 저수조 → 서쪽 터널 → 아래 터널)을 따라 동쪽 끝 배수구 철창으로 나간다.

## 2. Core Facility Identity
"보행로 – 물길 – 보행로" 세 줄 단면의 터널이 S자로 세 번 꺾이고, 한복판에 원형 저수조가 있다. 물길은 6스터드 낮아 철제 다리로만 건넌다. 다른 챕터에는 없는 '물길로 나뉜 평행 보행로'가 뼈대다.

## 4. Optional Supporting Zones
공구 창고 둘, 정비 작업장(x6~13, y12~18), 배관 자재실, 저장고, 작업장 옆 좁은 틈(막다른 곳: 숨는 곳만), 서쪽 위 터널의 무너진 끝.

## 5. Zone-to-Zone Flow
띠마다 터널과 방 줄이 나란히 간다. 위 띠: T1 또는 공구 창고–펌프실–밸브실–관리 사무실. 동쪽 꺾임: V2 또는 배수 제어실. 가운데 띠: 가지 터널 / 제어실 줄 / 침전조가 저수조 둘레 고리로 모였다가 가지 터널 / 작업장 / 침사지로 갈린다. 서쪽 꺾임: V1 또는 수문실 아래 문. 아래 띠: T3 또는 공구 창고–자재실–오수 펌프장–저장고–점검실.

## 7. Landmark Features
원형 저수조(기둥 넷과 물웅덩이), 펌프 다섯 대가 선 펌프실과 머리 위 배관 줄, 저수조 물길 입구의 철창, 수문 승강기, T1·T3 한가운데의 무너진 구간.

## 8. Sonar Readability
아치 갈비와 다리 난간이 규칙적인 윤곽을 만들고, 물길은 낮은 빈 띠로 읽힌다. 장비는 원통 몸통과 손바퀴처럼 굵은 윤곽 위주다. 작은 부품은 음파를 막지 않는다.

## 9. Gameplay Integration
- 길: 주 135칸 / 보조 171 / 대체 173.
- 괴물 하나(3x3)를 어디 세워도 시작→출구·시작→각 Z·각 Z→출구가 끊기지 않는다(목 0). 괴물 둘 무작위 0.3%(S→E), Z→출구 최악 0.6%. 정확히 r34c40 + r38c40(출구 바로 앞 터널과 점검실)에 둘이 서면 끊긴다(경고).
- 배회 흉내 200판: 기다린 판 3(1.5%). 다른 시드로 1000판을 돌리면 40(4.0%).
- 게임 안 경로 함수(StageBuilder `route`)는 벽 상자 c·배관 v 칸을 막힘으로 보는데 검사 도구는 지나갈 수 있는 칸으로 본다. 이전 판은 그 규칙으로 재면 목이 3곳이었다. 좁게 남은 남쪽 보행로 위 상자 두 개(20,9)·(26,35)를 빼서 **두 규칙 모두 목 0**이 되었다.
- 숨는 곳 L 20곳, 열쇠 상자 Z 18곳(모두 문 둘 이상인 방이나 터널 벽).

## 10. Visual Authenticity Review (자체 점검)
- 정비 출입구 → 펌프·밸브 → 저수조 → 수문 → 오수 펌프장 → 배수구로 실제 배수 흐름 순서다. ✔
- 구역마다 용도에 맞는 장비가 있다. ✔
- 약점: 아래 띠 방 줄(공구 창고·자재실·저장고)은 크기가 비슷해 반복감이 있다.
- 약점: 검사 도구의 '고리' 값이 0으로 나온다. 터널이 문 없이 이어져 한 구역으로 세이기 때문이며, 실제 순환은 저수조 고리와 띠마다의 두 갈래로 여러 개다.
