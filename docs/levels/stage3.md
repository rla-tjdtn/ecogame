생성기 `tools/places/sewer.js` → `src/server/Stages/Stage3.luau`, 전용 장비 `src/server/ChapterProps/Sewer.luau`. 괴물 2마리.

## 1. Chapter Theme
도시 밑 합류식 하수망. 지상 맨홀로 내려온 상류 낙차 맨홀실에서 시작해, **오수가 흐르는 방향 그대로** 간선을 따라 내려가 배수 펌프장의 지상 계단으로 나간다. 출구 계단은 시작 맨홀 바로 옆 땅속에 있지만 그 사이는 흙이라, 물길을 따라 하수망을 한 바퀴 돌아야 닿는다.

## 2. Core Facility Identity
**나뭇가지(수지상) 하수망**: 굵은 간선 차집관로(보행로 2칸 / 수로 / 보행로 2칸, 5칸 폭)가 맵 가장자리를 따라 북 → 서 → 남 → 동으로 흐르고(동쪽 끝은 펌프장, 북동쪽 시작과는 이어지지 않는다), 안쪽에서 3칸 폭 지선들이 간선으로 흘러든다. 지선이 모이는 마디가 원형 우수 저류조·침사지·월류 위어실이고, 물이 끝나는 곳이 배수 펌프장이다. 예전의 "가로 띠 셋 S자 + 띠마다 사무실 같은 방 줄"을 버렸다.
수로 w 는 6스터드 낮은 물길: 철제 다리 b 로만 반대편 보행로로 건넌다. 지선이 간선에 합류하는 곳은 보행로 밑으로 물이 들어가는 철망 다리(b 두 칸)라 보행로가 끊기지 않는다.

## 5. Zone-to-Zone Flow
물 흐름 = 길: 낙차 맨홀실 → 북쪽 간선(두 보행로) → [갈래 ①] 간선 그대로 북서 합류실 / [갈래 ②] 지선 A → 저류조 고리 → 지선 B → 서쪽 간선 → [갈래 ③] 서쪽 간선 그대로 남서 합류실 / [갈래 ④] 지선 D → 침사지 → 지선 → 남쪽 간선 → [갈래 ⑤] 남쪽 간선 → 남동 굽이 → 동쪽 간선 → 스크린·집수정 / [갈래 ⑥] 월류 지선 → 위어실 → 뒤 통로 → 펌프실 → 지상 계단실.
갈래마다 두 길이 다시 같은 간선으로 모이지만 모이는 곳이 넓은 합류실·2칸 보행로 둘이라 괴물 하나로 막히지 않는다(목 0). 북쪽 시작과 동쪽 펌프장 사이(맵 동쪽 x34~45, y8~12 위)는 흙이라 이어지지 않는다.

## 7. Landmark Features
상류 낙차 유입관에서 떨어지는 오수(시작), 수로 위를 벽에서 벽까지 가로지르는 굵은 배관 다리 둘(서쪽 간선 입구·남쪽 간선 가운데), 원형 저류조 한가운데로 천장에서 떨어지는 빗물 기둥, 침사지의 넓은 물길, 월류 위어, 펌프 넷이 선 펌프실, 5칸 폭 간선의 넓고 낮은 아치 갈비(지선은 둥근 아치 — 폭으로 간선·지선이 구별된다).

## 8. Sonar Readability
- 아치 갈비를 세 칸마다로 줄이고(예전 물 칸마다) 벽에서 벽까지 한 줄로 그려, 터널 단면이 규칙적인 리듬으로 읽힌다. 간선(넓고 낮은 아치)과 지선(둥근 아치)이 단면 모양으로 구별된다.
- 물길은 낮은 빈 띠 + 양쪽 난간(빌더가 구덩이 가장자리에 짓는다)으로 보인다.
- 벽 배관 확률을 0.8 → 0.2 로 낮췄다(아치 갈비·수로 난간이 이미 선을 많이 그리고, 배관은 볼트까지 부품이 많다).
- 열쇠 상자·숨는 곳을 2칸 보행로 위가 아니라 벽을 판 오목한 자리에 두어 보행로 윤곽이 끊기지 않는다.

## 9. Gameplay Integration
- 길(검사 도구): 주 131칸(북쪽 간선 → 서쪽 간선 → 지선 D·침사지 → 남쪽 간선 → 월류 지선·위어실 → 펌프실 → 계단실) / 대체 149칸(지선 A → 저류조 → 지선 B → 침사지 → 남쪽 간선 → 남동 굽이 → 동쪽 간선 → 집수정 → 계단실) / 보조 159칸(바깥 보행로로 간선만 따라 한 바퀴).
- 괴물 하나(3x3)를 어디 세워도 시작→출구·시작→각 Z·각 Z→출구가 끊기지 않는다(목 0). 간선은 보행로 2칸 + 수로라 괴물 하나가 한쪽 보행로를 막아도 반대편이 열려 있다.
- 출구 깔때기: 지상 계단실은 문 넷 — 펌프실 문 둘(월류 통로 쪽에서 옴)과 집수정 서·동 보행로 문 둘(동쪽 간선의 두 보행로에서 옴). 정확히 막는 두 자리 r21c32(펌프실 서쪽 문 안) + r17c41(집수정 서쪽 보행로)은 서로 다른 통로다(경고 수준).
- 숨기: 정비 사물함 L 18곳(벽 오목한 자리, 막다른 방), 공구함 Z 20곳(모두 문 둘 이상인 방·합류실·저류조·터널 벽 오목한 자리).
- 공포 흐름: 떨어지는 오수 소리 속 좁은 낙차실(시작) → 긴 간선(어둡고 곧은 터널, 물소리) → 원형 저류조·침사지의 넓은 홀(해방) → 막다른 지선·수직갱(긴장) → 펌프실의 기계 줄 → 계단실.

## 10. Visual Authenticity Review (자체 점검)
- 실제 하수 시설 구역(상류 맨홀·낙차, 간선 차집관로, 지선, 합류 맨홀실, 우수 저류조, 침사지, 월류 위어, 스크린, 집수정, 펌프실, 발전기실, 밸브실, 수직갱, 관리 사무실)이 있고 물 흐름 순서로 이어진다. ✔
- 사무실 같은 네모 방 줄을 없앴다. 사무실은 하나(관리 사무실), 나머지 방은 모두 하수 설비 공간이다. ✔
- 빈 방이 없다(6절 표). ✔
- 약점: 간선이 맵 가장자리를 도는 모양이라 멀리서 보면 "바깥 고리"처럼 보일 수 있다. 다만 고리가 닫히지 않고(북동 시작 ↔ 동쪽 펌프장 사이가 흙), 가운데는 봉인된 방이 아니라 지선 나무다 — 1장(바깥 고리 + 봉인된 가운데 방, 출구가 가운데)과 출구 위치·가운데 구조가 다르다.
- 약점: 검사 도구의 '고리' 값이 음수(-19)로 나온다. 터널이 문 없이 이어지고 수로 칸이 따로 세어지는 탓이며, 실제 순환은 위 5절의 갈래 셋(저류조·침사지·월류)이다.

## 남은 문제
- Studio 실기(짓기·부품 실측·실제 길찾기·음파)와 사람 플레이는 아직 안 했다. 새 소품(Channel·DropInlet·PipeBridge·Weir·ManholeShaft)은 luau-analyze 로 문법만 확인했다.
- 부품 추정이 10,000 선에 가깝다(대부분 빌더가 짓는 수로 난간). 실측이 넘으면 합류실 안 수로 길이를 줄이거나 벽 배관을 더 줄인다.
- 출구 계단이 시작 맨홀실 바로 아래 땅속(8칸 거리)이라 지도에서 가까워 보인다 — 의도(한 바퀴 돌아와야 한다)지만 플레이어 반응은 확인이 필요하다.
- 괴물이 수로(구덩이 칸)를 배회 지점으로 쓰지 않는다(Walkable 에서 뺐다). 다리 위에서 엇갈리는 상황은 Studio 에서 확인해야 한다.
