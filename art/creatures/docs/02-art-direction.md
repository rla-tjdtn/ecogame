# 괴물 전면 개편 — 2. 아트 디렉션

## 정체성
검은 바탕 + 흰 2D 선. 3D·사실 렌더링 금지. 흰 채움은 이유가 있을 때만(눈의 흰자 등). 붉은색은 괴물당 한 곳.
게임에선 음파가 닿은 모서리만 잠깐 빛남 → **실루엣과 핵심 선 20~60개로 읽혀야 한다.**

## 챕터마다 두 종류 (필수)
- **사람형 = 움직임이 사람**: 두 다리로 체중을 옮기고 균형을 잡는다(겉모습은 사람이 아니어도 됨).
- **비인간형 = 자기만의 이동**: 네발, 끌기, 기어오르기, 역관절, 미끄러짐 등 자기 방식으로 무게를 싣는다.
- 한 챕터의 두 괴물은 실루엣·동작·구조·공간 사용(바닥/벽/천장/가구 밑)·소리·접근 방식·공포의 종류가 모두 달라야 한다.

## 금지
- 몸·팔다리 리그 재사용, 머리만 바꾸기. / 긴 팔다리·큰 입·이빨에만 기대기. / 유명 공포 IP 따라하기. / 해파리·뱀·애벌레(사용자 거절).
- 만화 눈, 이모티콘 미소, 차렷 자세, 상자 쌓은 몸, 떠 있는 부품(사용자 거절 이력).

## 괴물마다 '공포 장치' 하나
그 챕터 공간과 묶인 규칙 하나(예: 선반 위에서 내려온다 / 등받이 너머로 돌아본다 / 소리 쪽으로 접시 얼굴을 돌린다). 게임 규칙과 연결 가능해야 함.

## 제작 단계 (괴물마다)
조사 → 브리프 → 실루엣 8개 이상 → 상위 3개와 이유 → 최종 선택 → 깨끗한 선화(굵기 위계, 선 절약, 매끈한 베지어) → 정면/측면/뒷면/3-4 일관성 → 애니메이션 가능성 → 음파 판독(일부/전체 노출, 가까이/멀리, 짧은 노출, 배경과 겹침).

## 독립 QA (디자이너 자기 승인 금지)
100점: 공포 20 · 독창성 20 · 실루엣 15 · 해부 10 · 선 품질 15 · 챕터 적합 10 · 음파 5 · 동작·소리 5. **90 미만 불승인.**
재작업 등급: 1 다듬기 / 2 구조 / 3 전면 재디자인, 전후 비교 첨부.

## 산출물 (괴물마다)
대표 컨셉 · 턴어라운드 · 해부 · 디테일 · 동작 포즈 · 음파 모습 · 게임 화면 목업 · 제작 사양서.
전체: 다양성 매트릭스 · 챕터별 나란히 비교 시트 · 마스터 현황표.

## 상태 표기 (정직하게)
완료·검증됨 / 완료·검증 필요 / 초안만 / 설계만(미제작) / 재작업 필요 / 도구 한계로 막힘. 실제 파일이 있는 것만 보고.

## 게임 구현
사용자가 승인한 괴물만. 괴물마다 고유 뼈대 + 고유 이동 애니메이션 + 고유 소리.
