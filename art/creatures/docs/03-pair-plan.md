# 괴물 전면 개편 — 3. 챕터별 짝 계획 (사용자 승인 대기)

시트: roster-concepts/v4-team/pairs1.png(1~5장), pairs2.png(6~10장). 왼쪽 = 사람형(두 발 이동), 오른쪽 = 비인간형.
v4 후보를 새 규칙으로 다시 판정한 **잠정안**. 독립 QA 점수는 아직 없음(지금까지는 아트 디렉터 검토뿐 → 지시상 '승인'이 아님).

| 장 | 사람형(두 발) | 비인간형 | 공포 장치(공간) | 상태 / 새 규칙 위반 우려 |
|---|---|---|---|---|
| 1 지하 시설 | 뼈 삼각 (게임에 있음) | 7번 사냥개 (네발) | 사냥개: 코를 바닥에 박고 음파 흔적을 따라옴 | 사냥개 초안 · 머리가 악어처럼 읽힘(재작업 2) |
| 2 물류 창고 | 진열 마네킹 (머리 대신 팔·손바닥 입) | 내려오는 것 (선반 거꾸로 기어 내려옴) | 마네킹: 선반 사이 진열품처럼 서 있음 / 내려오는 것: 위 공간 | 둘 다 초안 · 마네킹 몸이 뻣뻣(재작업 1) |
| 3 하수도 | **없음 → 새로 디자인** | 익사체 (긴 네발) | 익사체: 물을 건너옴 | 익사체가 '긴 팔다리'에 기댐(재작업 2). 꽃괴물(기존)은 별도 유지 여부 결정 필요 |
| 4 폐병원 | 갈라진 환자 (링거대, 끄는 다리) | 뒤집힌 환자 (게걸음) **사용자 승인** | 끄는 발소리 + 링거대 바퀴 / 거꾸로 빠르게 | 갈라진 환자 초안 |
| 5 심층 미로 | 얼굴 없는 키다리 (물음표 자세) | 웅크린 것 (정면 거미 자세) **사용자 승인** | 키다리: 천장 높이·모퉁이 / 웅크린 것: 바닥 | 키다리가 '긴 팔다리'에 기댐(재작업 1~2). 대안: 귀 기울이는 것(역관절, 소리 사냥) |
| 6 호텔 | 지배인 (90° 인사) | 문틈의 여자 (문·천장을 타고 이동) | 인사하며 다가옴 / 문틈에서 내다봄 | 초안. 문틈의 여자 이동 방식 설계 필요 |
| 7 학교 | 담임 (고개 180°) | 책상 위의 아이 (책상 사이를 네발로 뜀) | 칠판 쪽을 보는 척 / 책상 위 높이 | 담임 '큰 입' 의존(재작업 1) |
| 8 폐유치원 | 술래 (숫자 세는 키다리) | 젖먹이 (기는 아기, 늘어난 목) | 술래: 눈을 가리고 셈, 손가락 틈 / 젖먹이: 우는 소리 | 젖먹이 '풍선 머리' 우려(재작업 1) |
| 9 지하 주차장 | 주차 안내원 (천장 밑 웅크림) | 차 밑의 틈 (차 밑에서 미끄러져 나옴) | 낮은 천장 / 차 밑 | 차 밑의 틈 가장 약함(재작업 2~3). 대안: 견인된 것(팔로 끌기) |
| 10 폐영화관 | 릴 머리 (필름 릴 머리) | 흔들리는 여자 (팔로 짚는 네발, 머리만 떪) | 영사 불빛 / 머리 떨림 잔상 | 초안 |

예비(쓰지 않은 후보): 포장된 남자(2), 척추 실험체(1), 상자 속(구), 견인된 것(9), 귀 기울이는 것(5), 속이 찬 토끼(8), 뒷줄 관객(10), 전학생(구) 등.

## 승인 후 진행 순서(지시 그대로)
괴물마다: 실루엣 8개+ → 상위 3 → 최종 → 깨끗한 선화 → 4방향 → 동작 포즈 → 음파 판독 → 독립 QA(90점 이상) → 사양서 → (승인된 것만) 게임 구현.
