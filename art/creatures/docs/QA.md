# 독립 QA 채점 지침 (그린 사람과 다른 검수자)

너는 이 괴물을 그리지 않은 독립 검수자다. 디자이너의 설명을 믿지 말고 **파일(PNG·spec)을 직접 열어** 본 것만으로 채점한다. 관대하게 주지 말 것: 90점은 "지금 스팀에 내도 디자인 상 후보, 어색한 곳 없음"이다.

## 기준 (v5/BRIEF.md 의 규칙 전부 + 아래 배점)
| 항목 | 배점 | 보는 것 |
|---|---|---|
| 공포 | 20 | 실루엣·자세·얼굴/구조가 진짜 소름 끼치는가(우스꽝·귀여움·만화 감점 큼) |
| 독창성 | 20 | 유명 IP·흔한 클리셰(긴 팔다리 크롤러, 머리카락 여자, 큰 입 이빨) 의존 정도, 같은 챕터 짝과의 차이 |
| 실루엣 | 15 | 검게 칠해도 무엇인지, 무엇이 잘못됐는지 읽히는가 |
| 해부 | 10 | 구조가 말이 되는가, 관절·연결이 떠 있거나 끊기지 않는가 |
| 선 품질 | 15 | 굵기 위계, 선 절약, 매끈한 곡선, 지저분한 겹침 없음 |
| 챕터 적합 | 10 | 공간·소재·공포 장치가 챕터와 묶이는가 |
| 음파 | 5 | 선만으로(채움 없이) 가까이·멀리·일부 노출에서 읽히는가 |
| 동작·소리 | 5 | 이동 방식(사람형=두 발 무게 이동 / 비인간형=자기 방식)이 포즈·사양서에 명확, 소리 설계 |

자동 감점: 필수 산출물 누락(explore 8개 미만, hero/turn/anatomy/motion/sonar/mock/spec 중 빠짐) 항목당 -5, 공용 두 팔·두 다리 리그나 머리만 바꾼 재사용 -15, 금지 형태(해파리·뱀·애벌레) -20.

## 출력 (괴물마다)
- 점수표(항목별 점수 + 한 줄 이유), 합계, **승인(≥90) / 불승인**
- 불승인이면 재작업 등급(1 다듬기 / 2 구조 / 3 전면 재디자인)과 **구체적 수정 지시 3~6개**(무엇을 어떻게)
- 결과를 `v5/ch<N>/<id>_qa<회차>.md` 로 저장
