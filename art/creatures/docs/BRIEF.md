# 음파 미로 괴물 전면 재제작 — 챕터 디자인 팀 브리프 (아트 디렉터)

## 0. 처음부터 다시
이전 시안(v1~v4, 승인된 4S·5S 포함)은 **정답이 아니다.** 각 챕터를 새로 탐색하고, 옛 아이디어는 새 탐색에서 실력으로 이길 때만 쓸 수 있다.
1장의 지금 메인(뼈 삼각)도 다시 디자인한다. 도플갱어(아바타 복제)는 시스템이라 대상 아님. 꽃괴물(3장)은 3장 팀 재량(흡수 또는 교체).

## 1. 게임 사실 (코드로 확인, creature-program/01-project-audit.md 참고)
- 1인칭, FOV 70. 완전한 어둠. 플레이어가 음파를 쏘면 35스터드 반경 안 **모서리 선만** 3.5초 빛남. 괴물은 맞으면 10초간 움직이는 그대로 보임.
- 화면 = 검은 바탕 + 흰 선. 괴물도 선(파트 모서리: 막대=실루엣 2줄, 얇은 막대=1줄, 공=원)으로만 보인다. **면·채움·명암은 게임에서 안 보인다.** 붉은 선은 괴물당 한 곳만 가능(SonarColor).
- 공간: 타일 1칸 = 8스터드(복도 폭 대략 8), 바닥 y=0, 천장 y=14(2층은 바닥 12·천장 26), 낮은 기어가는 통로 있음(유치원). 플레이어 키 약 5. → 괴물 높이 상한 약 13.
- 선 개수 예산: 괴물 하나가 대략 40~120 선분. 너무 많으면 맵 선을 밀어낸다.

## 2. 챕터마다 두 괴물 (필수)
- **사람형 = 사람처럼 두 발로 무게를 옮기며 걷는다**(겉모습은 사람일 필요 없음).
- **비인간형 = 자기만의 이동**(네발, 끌기, 기어오르기, 벽·천장, 미끄러짐, 굴러감, 뛰어오름 등).
- 두 괴물은 실루엣·동작·구조·공간 사용(바닥/벽/천장/가구 밑/높이)·소리·접근 방식·공포의 종류가 전부 달라야 한다.
- 각 괴물은 그 챕터 공간과 묶인 **공포 장치 하나**(게임 규칙으로 구현 가능해야 함. 예: 음파를 쏘면 멈춘다 / 소리 쪽으로 몸을 돌린다 / 천장에서 떨어진다).

## 3. 금지
몸·팔다리 리그 재사용, 머리만 바꾸기 / 긴 팔다리·큰 입·이빨에만 기대기 / 유명 공포 IP(특정 캐릭터 생김새·이름) / 해파리·뱀·애벌레 / 만화 눈·이모티콘 미소·차렷 자세·상자 쌓은 몸·떠 있는 부품 / 3D·사실 렌더링.

## 4. 파이프라인 (괴물마다, 순서대로, 파일로 남길 것)
1. **조사·브리프**: 챕터 공간·소재·공포 장치·움직임 한 문단(spec 첫 부분).
2. **실루엣 탐색 8개 이상**: 서로 정말 다른 몸 구조(채운 검은 실루엣 또는 굵은 윤곽). 한 장 `<id>_explore.png`.
3. **상위 3 + 이유**, **최종 1** (spec 에 기록).
4. **깨끗한 선화(대표 컨셉)**: 흰 선만(채움은 검정 BG), 선 굵기 위계(외곽 2.2~2.6 / 구조 1.4~1.8 / 디테일 0.9~1.2), 선 절약, 매끈한 베지어. `<id>_hero.png`.
5. **턴어라운드**: 정면·측면·뒷면·3/4 — 비율·부위 일관. `<id>_turn.png`.
6. **해부/구조 + 디테일**: 뼈대(관절 계층) 도식과 핵심 부위 확대. `<id>_anatomy.png`.
7. **동작 포즈 4개 이상**: 대기·이동 2단계·공격/돌진(이동 방식이 보이게). `<id>_motion.png`.
8. **음파 판독**: 같은 괴물을 (a) 전체 노출 가까이 (b) 멀리(작게) (c) 일부만(원형 마스크로 반만) (d) 배경 선(벽·바닥 선)과 겹쳐서. 선만, 채움 없음. `<id>_sonar.png`.
9. **게임 화면 목업**: 1인칭 복도(바닥·벽·천장 원근 선) 안에서 음파에 드러난 모습. `<id>_mock.png`.
10. **제작 사양서** `<id>_spec.md`: 크기(스터드), 뼈대 계층(뼈 이름·부모·길이), 이동 방식(보행 주기, 접지점, 속도감), 공포 장치의 게임 규칙, 소리 설계(걸음·특수·추격, CC0 검색어), 선분 예산, 붉은 선 위치, 애니메이션 가능성 메모.

## 6-1. 재작업 공통 지침 (1차 QA 결과 반영, 아트 디렉터)
1차 QA 에서 공통 감점: 3D 원통·캡슐·깡통 부품 그대로 그린 선이 **마네킹/CAD/로봇**처럼 보임, 우스꽝스러운 형태 오독(선풍기·하트·고양이·둥근 만화 머리), 엉킨 팔.
- **hero·turn·anatomy·motion 은 '삽화 선화'로**: 3D 모델은 뼈대·비율 기준으로만 쓰고, 선은 유기적인 윤곽(가늘어지는 팔다리, 근육·뼈 돌출, 휘어진 외곽선, 끝이 뾰족해지는 선)과 굵기 위계로. 원통 두 줄 + 끝 링 같은 기계 선 금지.
- **sonar·mock 만 '게임 LOD'(파트 모서리 선)**: 단, 파트도 원통 일색이 아니라 가늘어지는 원뿔·여러 마디·쐐기로 나눠 유기적으로 보이게(게임에서도 그렇게 만들 것).
- 음파 판독에서 엉뚱한 물체(하트·선풍기·고양이·로봇)로 읽히지 않는지 반드시 멀리·일부 노출에서 확인.
