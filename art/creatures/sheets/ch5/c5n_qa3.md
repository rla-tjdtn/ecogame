# c5n 지움 — 독립 QA 3회차 (최종)

확인한 파일: c5n_hero / turn / motion / sonar / mock / thumbs / before_after .png (이번 회차 새로 그림), c5n_anatomy / explore .png (재렌더 안 됨), c5n_spec.md, c5n_qa2.md. 기준선: 승인 시안 4S·5S (roster/r2.png·r3.png).
규칙 판정 기준: 첫 음파에 맞으면 안 보이고, 3.5초 안에 다시 맞아야 드러남 — 사양 6절(1.5~3.5초 창, `SonarHidden`)과 일치, 구현 가능.

## 산출물끼리 어긋남
- **hero·turn·motion(새 선화) ↔ sonar·mock(게임 LOD)이 서로 다른 괴물**: 선화는 바깥으로 휜 갈고리 갈비 + 빈 붉은 창 안에 척추만, LOD는 **가로 평행 갈비가 창을 꽉 메운 6각 통(사다리/술통/거북 등딱지)** + 붉은 테가 바깥 외곽. 플레이어가 실제로 보는 것은 LOD 쪽이므로 2차 지시 2(창을 비워라)는 게임 화면에서 미이행.
- **anatomy**(재렌더 안 됨): 닫힌 가로 갈비 + 두 팔 V 자세(폐기된 2차 안). 새 hero와 불일치.
- 선분: 시트 표기 **92 / 파트 47**, 사양 8절 "약 84 / 파트 40", 3절 "파트 36" — 숫자 셋이 다름. 92는 예산(40~120) 안이지만 1차에서 요청한 70~90은 넘음.

## 2차 수정 지시 이행 여부
1. X 만세 깨기·손발 4점 접지: **일부** — 선화에선 만세는 사라졌으나 왼팔이 여전히 높이 들림, LOD 손발은 벽에 안 닿음
2. 가슴을 실제로 열기(갈고리 갈비·빈 창·4쌍): **선화 완료 / LOD 미이행**
3. 비대칭을 정면에서: **완료**(오른쪽 맨 아래 갈비 처짐 보임)
4. 게임 LOD 재제작(원뿔 마디·판 손·쐐기 골반): **일부** — 캡슐·번짐은 없어졌으나 골반 두 덩어리, 손 = 타원, 가슴 구조 불일치
5. 공격 포즈 겹침 없이: **완료**

## 남은 수정 지시
1. LOD 가슴을 선화와 같게: 척추 1 + 바깥으로 휜 갈고리 갈비 4쌍(쐐기 원뿔), 가운데는 **비워** 붉은 테 안에 척추만.
2. 갈비 끝을 아래·뒤로 꺾고 길이를 줄여 곤충 다리 오독 제거(갈비가 팔다리보다 눈에 띄면 안 됨). 64px 썸네일로 재확인.
3. 손발 4점이 목업·음파에서 벽/바닥 선에 정확히 닿게(IK 목표 = 통로 면).
4. 골반 = 쐐기 판 2, 목 단면 = 원통 뚜껑 대신 찢긴 불규칙 테.
5. 선분·파트 숫자를 하나로(목표 ≤90) 맞추고 anatomy 재렌더.

## 최종 상태 (솔직한 한 문단)
지움의 게임 규칙(첫 음파엔 선 0, 3.5초 안 두 번째 음파에 노출)은 이 게임에서 가장 독창적인 장치이고 구현도 간단하게 확정됐다. 그러나 몸은 세 번의 회차 동안 61→65→66으로 거의 오르지 않았다. 새 선화는 깨끗하지만 디자이너가 걱정한 대로 갈비가 곤충 다리로 읽혀 "지네/바퀴벌레 인간"이 되었다. 플레이어가 실제로 보게 될 게임 LOD는 선화와 다른 꽉 찬 통 모양이다. 승인 시안 4S의 "한눈에 잘못된 사람 몸"과 비교하면 아직 멀다. 공포 장치는 살리고 몸은 선화·LOD를 한 구조로 묶어 다시 만들어야 한다.
