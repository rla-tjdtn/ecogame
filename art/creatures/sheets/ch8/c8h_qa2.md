# c8h 눈높이 — 독립 QA 2회차

확인한 파일: explore·hero·turn·anatomy·motion·sonar·mock·before_after·spec(현재본). 디자이너가 다시 보지 않았다는 anatomy·motion·sonar 도 직접 열어 확인. 누락 없음, 고유 리그(무릎 접지).

**판정: 불승인** — 재작업 등급 **3 (선화·게임 LOD 전면 재작업, 개념은 유지 가능)**

## 1차 수정 지시 이행 여부
1. 길쭉한 성인 두개골·무표정 → **부분**: spec·anatomy 에선 그렇다고 하나 hero·turn 에서 머리가 어깨 혹과 구분되지 않는다.
2. 목 꺾임·머리가 어깨선 아래 가슴 앞 → **부분/불명확**: 위치는 낮아졌으나 측면에서 목 선이 보이지 않는다.
3. 상자/원통 팔 → 마른 성인 팔 → **선화 부분 / 게임 LOD 미완**: sonar·mock 은 여전히 상자 마디 로봇 팔.
4. hero 두 팔 분리 → **부분**: 겹침은 줄었으나 왼손이 무릎 앞 거대한 손이 되어 새 어색함.
5. 붉은 자국 직선 1~2줄 → **완료**.
6. 무릎 걸음 무게 이동 과장 → **미완**: motion 1~3 차이가 미미, 끌리는 정강이 궤적 없음.

## 수정 지시 (2차)
1. hero 를 측면 3/4 로 다시: 등 곡선 → 어깨 → 앞-아래로 꺾인 목 2마디(선 분명히) → 가슴 앞에 매달린 길쭉한 머리가 위로 얼굴을 든 모습이 **한눈에** 보이게. 머리 외곽선은 몸 외곽과 겹치지 않게 분리.
2. 손 크기를 머리 길이의 0.7~0.8로 줄이고 손가락은 길이·마디가 다르게. 왼손 손등 끌기는 바닥선 위에 납작하게.
3. 게임 LOD 팔·손을 상자 마디에서 **가늘어지는 원뿔 2마디 + 쐐기 손**으로 바꿔 sonar·mock 의 로봇 판독을 끊어라. 얼굴은 눈꺼풀 2·입 1 선이 멀리서도 보이게 길이 확보.
4. mock 을 플레이어 눈(5)에서 내려다보는 원근으로 다시 — 괴물 머리가 시야 아래쪽, 높이 3.4로 낮게 보여야 '눈높이' 규칙이 읽힌다.
5. motion 2·3 에서 들린 무릎 높이·골반 기울기(±8°)를 눈에 띄게, 끌리는 정강이 궤적 점선 추가. 포즈 차이가 실루엣만으로 구분되게.
6. turn 을 패널 안에 맞추고(손 침범 제거) 네 뷰의 팔 배치를 같은 포즈로 일치.
