## 1차 수정 지시 이행 여부
1. 하트/W 판독 제거, 수평 원·납작한 타원 → **미완**: spec 수치(어깨 2.55 균일)는 바뀌었으나 그림은 여전히 하트/W. 3/4·정면이 원근 타원으로 그려지지 않았다.
2. 성인 어깨 크기·목 그루터기·쇄골, 팔 겹침 제거 → **부분**: 크기는 커졌으나 그루터기가 깡통 뚜껑, 빈자리 쪽 팔 겹침 남음.
3. 원통 팔 → 마른 사람 팔 → **미완**: 선화·LOD 모두 원통 2마디.
4. mock 을 넓은 놀이방 고리 안 시점으로 → **부분**: 구도는 바뀌었으나 판독 실패(퍽 + 엉킨 막대).
5. 턴 크게·평면도 추가 → **부분**: 평면도 추가 완료. 위 절반 빈 화면은 그대로이고 그림 크기도 거의 같음.
6. 팔 이중선·매듭 정리 → **거의 완료**.

## 수정 지시 (2차)
1. 하트/W 의 근본 원인은 매듭 손을 바닥(0.16)까지 내린 채 어깨를 2.55에 둔 **V자 팔**이다. 팔을 거의 수평(매듭 높이 1.2~1.6, 팔꿈치 약간 처짐)으로 바꾸고 디딤은 매듭 대신 다른 접지(예: 각 어깨 아래 늘어진 척추 그루터기)로 옮겨, 측면·정면에서 수평 띠 + 원근 타원으로 읽히게 하라.
2. hero 를 위에서 내려다본 평면 대신 **낮은 3/4 원근**(눈높이 5)으로 다시 그려 고리가 납작한 타원으로 보이게. 빈자리는 타원 옆면.
3. 목 그루터기 원통 뚜껑을 없애고 잘린 목 = 짧게 찢긴 외곽선 + 쇄골 2선. 게임 LOD 도 원판 대신 쐐기 2개로(퍽/의자 판독 제거).
4. 팔을 원통에서 가늘어지는 원뿔 2마디(어깨 굵고 손목 가늘게) + 팔꿈치 돌출로.
5. mock: 플레이어 주변 4~5개 어깨가 화면 양옆·뒤 가장자리에 걸치고, 앞에 붉은 손 틈 하나 — 붉은 손은 손가락 4~5선이 보이게 크게. 가운데 엉킨 막대 무더기 제거.
6. 턴 시트의 빈 위 절반을 없애고 그림을 1.5배로.
