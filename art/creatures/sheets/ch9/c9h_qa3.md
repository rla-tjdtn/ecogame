## 2차 지시 이행
1. 진행 쪽 C 볼록 → 외곽은 완료, 판독은 '절하는 사람' 그대로.
2. 테이프 한 장 → hero 완료 / anatomy 미반영.
3. 가슴 공 삭제 → 반대로 몸 전체가 콩 덩어리.
4. LOD 쐐기 척추·X 삭제 → LOD 완료, spec 미갱신.
5. 3/4 mock → 완료.

## 남은 수정 지시
1. 몸통을 콩·상자 대신 마른 흉곽(가는 허리 + 튀어나온 척추 돌기)으로, 정면·측면이 같은 몸이 되게.
2. '뒤로 걷는다'가 화살표 없이 읽히도록: 손바닥이 진행 쪽으로 펴져 더듬고, 얼굴은 진행 반대쪽 아래에서 위를 보는 단서를 크게.
3. anatomy 를 새 hero 기준으로 다시 그리고, spec 선분 내역에서 X 띠 삭제.

## 최종 상태
1차 54 에서 61 로 오른 것은 만화 조끼·장화를 걷어낸 덕이지만, 3차의 2D 형태는 콩 몸통·상자 정면이라 오히려 우스운 쪽으로 기울었고 핵심 판독('등이 앞, 뒤로 걸어온다')은 그림만으로는 여전히 성립하지 않는다. 시트 간 불일치(anatomy)도 남아 있다. 불승인.
