# c9h 후방감지 — 제작 사양서 (9장 지하 주차장 · 사람형)

## 1. 조사·브리프
지하 주차장 = 낮은 콘크리트 천장, 끝없이 반복되는 기둥, 같은 모양의 주차 칸, 주차된 차, 경사로. 여기서 귀에 익은 소리는 **후진 경고음과 주차 센서의 "삐 — 삐 — 삐삐삐"**다. 이 괴물은 그 센서를 몸에 단 **주차요원**이다: 언제나 뒤로 걷고, 등이 앞이며, 허리의 범퍼 띠에 박힌 둥근 센서 4개로 거리를 잰다. 머리는 뒤로 완전히 꺾여 **거꾸로 된 얼굴이 제 등 위에서 눈을 감은 채** 다가오는 쪽을 보고, 두 손은 후진하는 사람처럼 뒤로 더듬는다. 소재 = 형광 조끼 X 띠, 범퍼, 주차 센서, 작업복·장화. 움직임 = 사람형(두 발 무게 이동)이지만 **뒤로**: 뒤로 뻗은 발이 발끝부터 닿고 뒤꿈치까지 내려 무게를 옮긴다. 공포 = 소리(점점 빨라지는 삐) + 보이는 것은 언제나 등.

## 2. 탐색 → 상위 3 → 최종 (c9h_explore.png)
8안: ①후방감지 ②충돌 더미 ③차단기 팔 ④기둥 흉내 ⑤헤드라이트 등딱지 ⑥안전벨트 묶음 ⑦번호판 얼굴 ⑧소화기 척추.
- **상위 3**: ① 후방감지 — 사람이 뒤로 걷는 어긋남 + 주차 센서라는 장소 소리, 게임 규칙(거리 = 삐 간격)이 바로 나옴. ② 충돌 더미 — 원형 표식이 음파에 잘 읽히지만 무섭기보다 기계적. ⑤ 헤드라이트 등딱지 — 실루엣은 강하나 "차 괴물"이 흔하고 공포 장치가 약함.
- **최종 = ① 후방감지**. 짝인 c9n(바닥에 납작, 소리 없이 차 밑)과 정반대로 **서 있고·시끄럽고·다가오는 소리로 무섭다**.

## 3. 크기 (스터드)
- 어깨 6.4, 어깨 위로 얹힌 머리 끝 7.4(꺾여서 실제 키보다 낮음), 어깨 폭 1.9, 뒤로 뻗은 손 끝 골반 뒤 1.9. 충돌 캡슐 반지름 1.0, 높이 7.4.

## 5. 이동 (사람형 — 뒤로 두 발 무게 이동)
- 보행 주기 1.2초: 뒤로 뻗은 발 발끝 접지(0.3) → 뒤꿈치까지 내려 무게 이동(0.3) → 앞발 들어 뒤로 지나감(0.6). 접지점 = 뒤로 가는 발의 앞꿈치→뒤꿈치.
- 속도: 순찰 5, 추적 9, 돌진(마지막 2타일) 18. 앞(얼굴 쪽)으로는 못 걷는다 — 반대로 가려면 3점 회전(1.8초).

## 6. 공포 장치 → 게임 규칙: "후방 감지음"
1. 센서는 **등 쪽 140° 부채꼴, 28 스터드**만 감지(벽 투과 안 됨). 얼굴 쪽(뒤통수 방향 = 플레이어가 그 뒤에 서면)은 사각.
2. 감지 중 삐 간격 = 거리: 28~16 → 1.2초, 16~8 → 0.6초, 8~3 → 0.25초, 3 미만 → 연속음 0.8초 후 돌진·잡기. **소리가 곧 거리계** — 플레이어는 듣고 판단한다.
3. 플레이어가 음파를 쏘면 그 지점으로 등을 돌려 호를 그리며 후진(차처럼 핸들을 꺾음). 그래서 음파 직후엔 괴물의 회전 1.8초가 틈.
4. 대기: 빈 주차 칸에 등을 통로 쪽으로 두고 "주차"해 있다(0.5초마다 낮은 삐). 칸 선·기둥 사이에서 등의 X 가 신호.
5. 대처: 얼굴 쪽(사각)으로 돌아 지나가거나, 기둥을 사이에 두어 센서 부채꼴을 끊는다.

## 7. 소리 설계
- 걸음: 고무 장화가 콘크리트를 뒤로 끄는 "끽 — 툭". CC0 검색어: `rubber boot step concrete`, `shoe scuff concrete garage`.
- 특수: 주차 센서 삐(1.5kHz 짧은 톤), 간격으로 거리 표현 + 낮은 울림(지하 잔향). 검색어: `parking sensor beep`, `reverse beeper`, `short beep 1khz`.
- 추격: 연속음 "삐———" + 조끼 반사띠 비닐 마찰 + 꺾인 목에서 나는 뼈 뚝. 검색어: `continuous beep tone`, `vinyl jacket rustle`, `neck crack bone`.
- 대기: 멀리서 들리는 후진 경고음 반복(위치 단서). 검색어: `truck reversing alarm distant`.

## 8. 선분 예산 (게임 음파)
- 게임 LOD 합계 ≈ **45개**. 머리 공 1, 목 2×2, 몸통 원통 2 + X 띠 2, 범퍼 3×2 + 센서 공 4, 팔 8 + 손가락 6, 다리 8 + 장화 4.
- X 띠는 얇은 파트 두 개(대각) — 음파에서 등 = X 로 즉시 읽힘.

## 9. 붉은 선 위치
**센서 2번(범퍼 왼쪽 안쪽) 하나**. 삐 소리가 나는 지점이자, 등이 이쪽을 향하고 있다는(=감지당하고 있다는) 신호.

## 10. 애니메이션 메모
- 뒤로 걷기는 일반 보행 클립을 거꾸로 재생하면 어색함 → 발끝 먼저 닿는 전용 키(뒤로 뻗는 발의 발목 각 +24°)를 둔다.
- 머리는 상체에 고정(목 2마디만 살짝 흔들림), 손은 진행 방향 IK 목표(벽·차 표면에 닿으면 손바닥 붙임).
- 3점 회전: 정지 → 골반을 30° 틀며 두 걸음 후진 → 반대로 틀어 정렬. 소리와 함께 "핸들 꺾는" 느낌.
