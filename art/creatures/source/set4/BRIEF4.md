# 시안 4 브리프 — 챕터마다 "딱 맞는 대표 공포 캐릭터" (아트 디렉터)

## 사용자 요청
"각 챕터에 딱 맞게, 컨셉에 맞게, 퀄리티는 더 좋게. 너무 기괴하기보다는 각 챕터에 딱 알맞은 **대표 공포 캐릭터**로, 훨씬 퀄리티 좋게."
→ 시안 3(`art/creatures/시안_인간형3`, `시안_비인간형3` 의 전체_*.png 참고)은 기괴함(얼굴 송이·선반 몸·눈알 머리 등)으로 갔다. 시안 4는 반대로:
- **한눈에 그 장소의 괴담 주인공**이라고 읽히는 캐릭터. 포스터·썸네일에 쓸 수 있는 '간판 괴물'.
- 실루엣이 깔끔하고 기억에 남는다(소품·복장·자세 하나로 정체가 보임). 디테일은 많아도 잡다하지 않게.
- 무서움은 "이상한 모양"보다 **그 장소에 있어야 할 사람/것이 잘못된 모습**에서 온다(자세, 비율 살짝, 얼굴, 상처, 망가진 소품).
- 퀄리티는 시안 3보다 높게: 해부(근육·관절·손발), 옷 주름, 소품 디테일, 얼굴 표현(A.face 실감 얼굴)을 더 정성껏.

## 지켜야 할 것
- 엔진: 이 폴더(`set4`)의 `sculpt.js`(SDF 조각 → 선화 렌더), `anat.js`(A.leg/arm/hand/foot/head/face/torso/ribs/spine/pelvis/neck/hair/fold/strap/rings/muscle/veins/stitch). **읽기 전용 — 고치지 말 것.** 시안 3 모듈(`../set3/e*.js`)이 사용법 예시다(특히 e1h, e4h, e7h, e8h, e10h).
- 붉은색은 괴물당 한 곳(`B.group({ mat: 1 })` 사용 예: set3/e1h.js 의 붉은 눈물).
- 해파리·뱀·애벌레형 금지. 유명 게임·영화 캐릭터 생김새·이름 금지(유형만 참고).
- 게임에서는 음파 선으로만 보인다 → 실루엣이 강해야 한다. 키는 대략 6~11스터드(천장 14).
- 챕터마다 사람형(`f<N>h`, 두 발로 걷는 것)과 비인간형(`f<N>n`, 자기 방식으로 움직이는 것) 둘. 두 괴물은 실루엣·움직임·공포 종류가 달라야 한다.

## 파일 (팀은 자기 파일만)
- 몸: `f<N>h.js`, `f<N>n.js` — set3 모듈과 같은 형식: `module.exports = { id, name, kind: '인간형 · N장 장소' 또는 '비인간형 · N장 장소', H, build(p) }`. 포즈 인자(p.walk, p.jaw, p.headYaw 등)는 자유.
- 설명·카메라·포즈: `meta4_<N>.js` — set3/meta3.js 와 같은 항목 형식 `{ f<N>h: { ch, place, yaw, low?, concept, fear, move, sonar, face: [[x,y,z], scale, yaw], hero: {...}, poses: [[이름, {...}], ...3개] }, f<N>n: {...} }`.
- 확인: `node look.js f<N>h` → `out/f<N>h_look.png` (Read 로 열어 본다, 3/4 크게 + 앞·옆·뒤). 확대: `node zoom.js <id> yaw pitch x y z scale` → out/zoom.png
- 완성: `node sheet.js f<N>h f<N>n` → `art/creatures/시안_인간형4/`, `시안_비인간형4/` 에 hero·sheet PNG.
- 렌더는 한 번에 10~20초. 다른 팀도 같은 out 폴더를 쓰니 파일 이름은 자기 id 로만.

## 품질 절차
1. 장소의 대표 괴담 캐릭터 후보 3개 → 가장 '간판'다운 것 선택(이유를 meta 의 concept 에 녹임).
2. 조각 → look 으로 3/4·앞·옆·뒤 확인 → 고침을 여러 번(최소 4회). 얼굴·손은 zoom 으로 따로 확인.
3. 체크: 한눈에 무엇인지 / 그 장소와 맞는지 / 우스꽝·마스코트 같지 않은지 / 해부가 말이 되는지 / 떠 있는 부품 없는지 / 붉은 곳 하나 / 시안 3보다 깔끔하고 정교한지.
4. sheet.js 로 최종 시트 → hero 와 sheet 를 Read 로 직접 보고 마무리.
