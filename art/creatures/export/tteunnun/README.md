# 뜬눈(k10h1) — 다른 게임용 3D 실사 괴물

에코포비아의 흰 선 음파 괴물(`art/creatures/source/game/out/mesh/k10h1*`, `src/**`)은 그대로 두었습니다. 이 폴더에 있는 것은 따로 만든 실사판입니다.
Roblox 업로드나 네트워크 호출은 하지 않았고 파일로만 만들었습니다.

**생김새는 시안 그대로입니다.** `source/set3/e10h.js` 시안 도형을 같은 SDF 도구(`source/game/sdfgrid.js`·`mesher.js`, 읽기만 함)로 고해상도 메시로 뽑았습니다.
그 위에 실사 재질과 뼈대·동작만 새로 입혔습니다. 손가락·갈비 테·속눈썹·갈고리 같은 가는 관은 그룹마다 따로 0.01 시안 단위(약 2mm) 격자로 뽑았기 때문에, 서로 녹아 붙지 않습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `tteunnun.blend` | 원본 작업 파일입니다. 조종 뼈(IK·시선)와 제약, 동작 9개(NLA 트랙)가 들어 있고, 텍스처는 `textures/` 를 상대 경로로 읽습니다. |
| `tteunnun.glb` | 메시, 변형 뼈 99개, 동작 9개, 텍스처(JPEG)를 담았습니다. 제약은 프레임마다 구워 넣었습니다. |
| `tteunnun.fbx` | 같은 내용이고, 텍스처는 `textures/*.png` 를 상대 경로로 가리킵니다. 엔진에서는 클립 이름이 `TteunnunRig\|Idle` 꼴로 보입니다. |
| `textures/` | 몸(`body_*`): 4096 크기 basecolor, normal(OpenGL), roughness, ao. 눈알(`eye_*`): 2048, 극좌표 UV. 동공(`pupil_*`): 512, emissive 추가. `body_normal.png`(22MB)는 커밋하지 않고 `run_all.sh` 로 다시 만듭니다(glb 안에는 들어 있음). |
| `renders/` | `look_*.png`(생김새)와 동작별 mp4(소리 없음), `all_clips.mp4`, `sheet.png` 입니다. |
| `tools/` | 다시 만드는 스크립트입니다. `bash tools/run_all.sh` 하나로 전부 다시 만듭니다(Edge GPU·Blender 5.2, 약 15분). |

## 메시와 재질

- 삼각형 약 6.9만 개. 재질 4칸: Body(피부·뼈·허리 넝마를 텍스처 한 벌에), Eye(흰자+홍채 구), Cornea(투명 각막, alpha blend), Pupil(동공 원판).
- 피부는 짙은 회색에 얼룩·푸른 핏줄·주름이 있고, 골에는 때가 끼어 있습니다. 튀어나온 뼈(갈비 테, 등뼈 돌기, 눈꺼풀 가장자리 손가락, 손가락)는 희뿌옇게 칠했습니다.
- 눈알은 시안의 눈 겉면을 빼고 따로 된 구로 바꿨습니다. 짙은 청회색 홍채에 충혈된 핏줄이 있고, 젖은 각막 아래 동공 원판 속에 작은 얼굴이 비칩니다.
- 키는 약 2.38m이고 단위는 미터입니다. 앞은 -Y(glTF 에서는 +Z), 왼쪽은 +X 입니다.

## 뼈대(변형 뼈 99개)

`Root > Hips > Spine1 > Spine2 > Spine3 > Neck > Head > {Eye > Pupil, EyelidUpper, EyelidLower, Hook_Up.L/R, Hook_Lo.L/R}`

- 뼈 자리는 시안 도형의 관절에서 직접 가져왔습니다(손가락 마디 = 시안의 마디 공 자리).
- 다리는 `UpperLeg / LowerLeg / Foot / Toes`(.L/.R) 입니다.
- 팔은 4개입니다. 앞팔 `_F`는 아래 눈꺼풀을, 뒤통수 위로 넘어온 뒤팔 `_B`는 위 눈꺼풀을 잡습니다. 팔마다 `Shoulder / UpperArm / LowerArm / Hand` 가 있고, 손가락 `Thumb, Index, Middle, Ring, Pinky` 마다 관절이 셋(1·2·3)입니다. 예: `Index2_F.L`
- 손가락 뼈는 로컬 +X 회전이 굽히기입니다. 눈꺼풀은 `EyelidUpper` +X, `EyelidLower` −X 가 감는 쪽입니다. 눈꺼풀 관과 속눈썹은 눈꺼풀 뼈에, 갈고리는 머리에서 갈고리 뼈로 섞여 붙어 있습니다.
- 동공 크기는 `Pupil` 뼈의 X·Z 스케일로 바꿉니다(1 = 보통, Stare 끝 1.9).
- `.blend` 에만 있는 조종 뼈:
  - 다리 IK: `IK_Foot.L/R` + `Pole_Knee.L/R`
  - 팔 IK: `IK_Hand_F/B.L/R` + `Pole_Elbow_*`. 머리에 붙어 있어서 손이 계속 눈꺼풀을 잡고 있습니다.
  - 시선: `EyeTarget`(Eye 의 Damped Track 표적)
- 웨이트: 메시의 연결 조각마다 가장 가까운 시안 그룹을 찾고, 그 그룹의 뼈로만 bone heat 자동 웨이트를 냈습니다. 정점당 4개로 제한하고 정규화했습니다. 극단 자세 검사(주먹, 손가락 뒤로 젖힘, 팔꿈치·손목, 쪼그려 앉기, 몸통 비틀기, 눈꺼풀·눈알)는 `tools/stress.py` 로 합니다.

## 동작(30fps, 제자리, 루트 이동 없음)

| 클립 | 프레임 | 반복 | 내용 |
|---|---|---|---|
| Idle | 91 | 반복 | 숨쉬기, 흔들림, 눈알 미세 도약, 눈꺼풀 떨림(감으려 함), 손가락 꼼지락, 갈고리 떨림 |
| Walk | 37 | 반복 | 구부정하고 뻣뻣한 걸음(IK 발 디딤), 걸으며 좌우를 훑음 |

| Attack | 46 | 한 번 | 젖혔다가 앞손이 눈꺼풀을 놓고 뻗어 움켜쥠. 아래 눈꺼풀이 처지다 갈고리에 걸림. 다시 잡음 |
| LookAround | 121 | 반복 | 눈이 먼저 돌고 머리·몸이 따라감 |

| Death | 76 | 한 번 | 휘청이다 무릎이 꺾여 뒤로 쓰러짐. 손이 눈꺼풀을 놓고 눈알이 뒤집힌 뒤 동공이 열림 |
| EyeDart | 61 | 반복 | 눈알이 2프레임마다 이리저리 튐 |
| Stare | 91 | 한 번 | 먼 곳을 응시하며 동공이 1.0에서 1.9로 커짐(속 얼굴도 커짐). 끝 자세 유지용 |

반복 클립은 끝 프레임이 첫 프레임과 같습니다. 엔진에서 반복할 때는 끝 프레임 하나를 빼고 돌리면 됩니다.
