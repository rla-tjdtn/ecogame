# 뜬눈(k10h1) — 다른 게임용 3D 실사 괴물

에코포비아의 흰 선 음파 괴물(`art/creatures/source/game/out/mesh/k10h1*`, `src/**`)은 그대로 두었고, 이 폴더의 것은 따로 만든 실사판입니다.
Roblox 업로드나 네트워크 호출은 하지 않았고 파일로만 만들었습니다.

## 만든 방법

- **몸·머리**: `source/set3/e10h.js` 시안 도형을 같은 SDF 도구(`source/game/sdfgrid.js`·`mesher.js`, 읽기만 함)로 메시로 뽑았습니다. 가는 관(갈비 테, 뼈 같은 굵은 속눈썹 등)은 그룹마다 따로 약 2mm 격자로 뽑았습니다(`tools/design_mesh.js`).
  - 시안에서 뺀 것(사용자 요청): 관자 쇠틀과 갈고리, 눈물 관, 눈 둘레의 굵은 주름 관, 시안 손과 팔(납작함)
- **눈꺼풀**(`tools/lids.py`): 눈알을 감싸는 살 띠입니다. 아몬드 꼴 눈구멍에 두툼한 위 눈꺼풀 주름과 처진 아래 눈꺼풀이 있고, 가장자리는 젖은 분홍 점막입니다. 눈 구석에는 분홍 살이 있습니다.
- **눈알**: 따로 된 구입니다. 또렷한 청회색 홍채(방사 섬유, 짙은 가장자리 고리, 동공 테 주름)와 충혈된 흰자, 검은 동공 원판, 투명 각막으로 되어 있고, 텍스처는 4096입니다.
- **팔·손**(`tools/limbs.py`): 앙상한 사람 팔 4개(삼각근, 뾰족한 팔꿈치 뼈, 두 뼈가 드러난 아래팔)와 사람 손(손바닥, 손가락마다 마디 3개, 손톱, 엄지)입니다. 손으로 눈꺼풀을 벌릴 만큼 깁니다(앞팔 0.52+0.50m, 뒤팔 0.70+0.64m).
- **묶는 자세(bind pose)는 팔을 펼친 자세**입니다. 앞팔은 옆으로, 뒤팔은 날개뼈에서 바깥·위로 펼쳐져 있고 손은 편 자세입니다. 눈꺼풀을 붙잡는 자세는 뼈대로 잡습니다. IK 목표를 눈꺼풀 가장자리에 두고 손가락을 굽혀 움켜쥡니다. 모든 동작이 이 붙잡는 자세에서 시작합니다.

## 파일

| 파일 | 내용 |
|---|---|
| `tteunnun.blend` | 원본입니다. 조종 뼈(IK·시선)와 제약, 동작 12개(NLA 트랙)가 들어 있고, 텍스처는 `textures/` 를 상대 경로로 읽습니다. |
| `tteunnun.glb` | 메시, 변형 뼈 95개, 동작 12개, 텍스처(JPEG)를 담았습니다. 제약은 프레임마다 구워 넣었습니다. |
| `tteunnun.fbx` | 같은 내용이고, 텍스처는 `textures/*.png` 를 상대 경로로 가리킵니다. 엔진에서는 클립 이름이 `TteunnunRig\|Idle` 꼴로 보입니다. |
| `textures/` | 몸(`body_*` 4096: basecolor, normal(OpenGL), roughness, ao), 눈알(`eye_*` 4096, 극좌표 UV), 동공(`pupil_*`). 20MB 가 넘는 png 는 커밋하지 않고 `run_all.sh` 로 다시 만듭니다(glb 안에는 들어 있음). |
| `renders/` | `bind_*`·`grip_*`(묶는 자세·붙잡는 자세), 동작별 mp4(소리 없음), `all_clips.mp4`, `sheet.png` 입니다. |
| `tools/` | 다시 만드는 스크립트입니다. `bash tools/run_all.sh` 하나로 전부 다시 만듭니다(Edge GPU·Blender 5.2, 약 25분). |

## 뼈대(변형 뼈 95개)

`Root > Hips > Spine1 > Spine2 > Spine3 > Neck > Head > {Eye > Pupil, EyelidUpper, EyelidLower}`

- 다리: `UpperLeg / LowerLeg / Foot / Toes`(.L/.R)
- 팔 4개: 앞팔 `_F`는 아래 눈꺼풀을, 뒤팔 `_B`는 위 눈꺼풀을 잡습니다. 팔마다 `Shoulder / UpperArm / LowerArm / Hand` 가 있고, 손가락 `Thumb, Index, Middle, Ring, Pinky` 마다 관절이 셋(1·2·3)입니다. 예: `Index2_F.L`
- 손가락 뼈는 로컬 +X 회전이 손바닥 쪽으로 굽히기입니다. 눈꺼풀은 `EyelidUpper` +X, `EyelidLower` −X 가 감는 쪽입니다(눈꺼풀 살 띠와 시안 속눈썹이 따라 움직입니다).
- 동공 크기는 `Pupil` 뼈의 X·Z 스케일로 바꿉니다(1 = 보통, Stare 끝 1.9).
- `.blend` 에만 있는 조종 뼈:
  - 다리 IK: `IK_Foot.L/R` + `Pole_Knee.L/R`
  - 팔 IK: `IK_Hand_F/B.L/R` + `Pole_Elbow_*`. 머리에 붙어 있어서 손이 늘 눈꺼풀을 잡습니다.
  - 시선: `EyeTarget`(Eye 의 Damped Track 표적)
- 웨이트: 연결 조각마다 맞는 뼈 묶음으로 bone heat 자동 웨이트를 냈습니다(팔·손은 만들 때 정한 묶음, 몸은 가장 가까운 시안 그룹). 눈꺼풀 띠는 계산식 웨이트입니다. 정점당 4개로 제한하고 정규화했습니다. 극단 자세 검사는 `tools/stress.py` 로 합니다.

## 동작(30fps, 제자리, 루트 이동 없음) — 12개, 모든 동작에 깜빡임·눈알 굴림

| Walk | 37 | 반복 | 구부정하고 뻣뻣한 걸음(IK 발 디딤), 걸으며 좌우를 훑음 |
