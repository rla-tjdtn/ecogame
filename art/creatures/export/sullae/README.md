# 술래 (k7h4) — 3D 실사판 (다른 게임용)

에코포비아의 흰 선 음파 괴물 술래(`art/creatures/source/set1/c8h.js`, 게임용 `out/mesh/k7h4.glb`)와는 **따로 만든 파일**이다. 원본은 하나도 고치지 않았다. Roblox에 올리지 않았고, 파일로만 둔다.

어른 키(2.15 m)의 마른 몸에 커다란 아기 머리가 붙어 있다. 손가락이 긴 손 네 개가 머리를 새장처럼 감싼다. 앞 팔 두 개는 손가락으로 눈을 가리고, 뒤 팔 두 개는 정수리를 덮는다. 몸통과 허벅지는 낡은 천을 감아 가렸다(맨살 몸통 없음). 팔다리에는 해진 붕대가 감겨 있다.

## 파일
| 파일 | 내용 |
|---|---|
| `sullae.glb` | 메시 4개, 스킨, 텍스처(JPEG로 포함), 동작 9개. 약 11 MB |
| `sullae.fbx` | 같은 내용. 텍스처는 `textures/*.png`를 상대 경로로 참조한다. 약 13.5 MB |
| `sullae.blend` | 원본 작업 파일. 고해상도 굽기 원본(약 164만 삼각형), IK 컨트롤, NLA 트랙 포함. **약 41 MB라서 git에 올리지 않았다** |
| `textures/sullae_{skin,cloth,eye,nail}_{baseColor,normal,roughness,ao}.png` | PBR 텍스처. 피부·천은 2048, 눈·손톱은 512 |
| `previews/*.mp4, *.gif` | 동작별 렌더. 소리 없음. `_full`은 몸 전체, `_face`는 얼굴 가까이 |
| `verify_glb.json`, `verify_fbx.json` | 내보낸 파일을 빈 장면에 다시 읽어 확인한 결과 |
| `tools/` | 다시 만드는 스크립트(Blender 5.2, `--background`) |

## 메시 (게임용 약 5.4만 삼각형)
- `Sullae_Body` 38,000: SDF 원형(캡슐·타원체 약 400개)을 부드럽게 합쳐 만들었다. 복셀 2.1 mm로 리메시한 뒤 부드러운 합집합 표면으로 투영하고 데시메이트했다. 사지가 붙는 곳은 이음새 없이 이어진다. 손가락 마디 혹과 주름, 손등 힘줄, 손가락 끝 살, 무릎, 복사뼈, 발가락 5개, 갈비뼈, 등뼈, 쇄골, 눈꺼풀, 콧구멍, 입술, 귀를 넣었다.
- `Sullae_Cloth` 11,000: 몸통을 감은 천과 붕대 6곳. 띠가 겹친 단차, 너덜너덜한 가장자리, 구멍이 있다. 양면 재질이다.
- `Sullae_Eyes` 약 1,700: 뿌옇게 흐린 눈알 2개. `Eye.L` / `Eye.R`로 굴린다.
- `Sullae_Nails` 3,120: 손톱 20개. 두껍고 끝이 손가락 밖으로 길게 자랐다.
- 노멀맵은 고해상도 메시(164만 삼각형)에서 구웠다. 색·거칠기·범프는 절차 셰이더를 구웠다. 피부는 창백한 회녹색에 정맥, 얼룩, 멍, 발쪽 때, 잔주름, 모공을 넣었고, 젖은 광택은 거칠기 변화로 표현했다. AO는 게임 메시끼리만 구웠다.

## 뼈대 (변형 뼈 94개 + IK 컨트롤 12개)
`Root, Hips, Spine1~3, Neck, Head, Jaw, Eye.L/R`, 다리 `Thigh/Shin/Foot/Toe .L/.R`, 팔 4개 `Shoulder/UpperArm/LowerArm/Hand _F(앞)/_B(뒤) .L/.R`, 손가락은 손마다 `Thumb/Index/Middle/Ring/Pinky` × 관절 1~3이다. 예를 들어 `Middle2_F.L`처럼 이름을 붙였다.
- 손가락 뼈의 로컬 X축 회전은 손바닥 쪽으로 굽히기, Z축 회전은 벌리기다.
- 웨이트: 자동(bone heat) 웨이트를 쓰고, 정점당 영향을 4개로 제한해 정규화했다. 좌우 팔다리 웨이트가 섞이지 않게 정리했다. 천은 가장 가까운 몸 정점 4개의 웨이트를 옮겨 받는다. 눈알과 손톱은 각자 뼈에 100% 붙였다.
- 극단 자세 검사(손가락 95°, 팔꿈치 120°, 허벅지 100°, 무릎 130°, 척추와 목 비틀기): 몸 모서리 최대 2.7배로 늘어남, 찢어짐 없음(한 덩어리 메시). 크게 접히는 관절 안쪽만 눌린다.
- IK: `IK_Foot.*`, `IK_Knee.*`, `IK_Hand_F/B.*`, `IK_Elbow_F/B.*` 컨트롤과 IK 제약을 넣었다. 동작은 FK로 구워져 있어서 기본은 꺼져 있다. 아마추어의 사용자 속성 `ik_on`을 1로 올리면 IK로 포즈를 잡는다. glb와 fbx에는 변형 뼈만 내보냈다.

## 동작 (30 fps)
| 클립 | 길이 | 반복 | 내용 |
|---|---|---|---|
| Idle | 3.0 s (90) | ○ | 머리를 감싼 채 숨쉬고 흔들린다. 손가락이 하나씩 꿈틀거린다 |
| Walk | 1.33 s (40) | ○ | 눈을 가린 채 휘청이며 걷는다(제자리) |
| Run (Chase) | 0.67 s (20) | ○ | 네 팔을 벌리고 손가락을 쫙 편 채 앞으로 기울어 달린다(제자리) |
| Attack | 1.33 s (40) | × | 웅크렸다가 네 팔로 덮치며 움켜쥐고 입을 벌린 채 끌어당긴다 |
| LookAround | 4.0 s (120) | ○ | 앞 손을 반쯤 열어 손가락 새장을 만들고 고개와 눈알을 좌우로 돌린다 |
| Hit | 0.67 s (20) | × | 머리가 뒤로 젖혀지고 팔이 움찔 벌어졌다가 다시 감싼다 |
| Death | 2.5 s (75) | × | 무릎이 꺾여 주저앉았다가 앞으로 고꾸라진다. 손가락이 갈고리처럼 오그라들고 경련한다 |
| Count | 4.0 s (120) | ○ | 눈을 가리고 넷까지 센다. 셀 때마다 고개를 꾸벅이고 입이 벙긋하며 손가락이 차례로 두드린다 |
| Peek | 3.0 s (90) | ○ | 왼쪽 앞 손의 가운데·약지 틈을 벌려 엿보고 눈알을 굴린 뒤 다시 닫는다 |

- 반복 동작은 마지막 프레임과 첫 프레임이 같아서 끊김 없이 이어진다. 프레임마다 키를 넣고 선형 보간한다. 손가락 움직임은 클립 길이의 정수배 주기로 만들었다.
- 머리를 감싸는 손은 머리를 기준으로 IK를 풀어 머리를 따라간다. 손가락 관절 각도는 머리 SDF 표면에 닿도록 접촉을 풀어 정했다.
- FBX를 Blender로 다시 읽으면 테이크 이름이 `Sullae|Sullae|Idle`처럼 앞에 이름이 붙어 나온다(가져오기 쪽 표기다). glb에서는 `Idle` 등 그대로 나온다.

## 다시 만들기
`sullae/` 폴더에서 `sh tools/build_all.sh`를 실행한다. 중간 산출물은 `work/`(git 제외)에 생긴다. 순서는 `build_geo → build_model → build_anim → export → verify → render_clips → make_videos`다.
